# Design System: Magical Girl — Starlight Dossier

## Overview

**Creative North Star: “The Starlight Dossier（星辉档案）”**

这不是一张套了粉色渐变的个人简介，而是在舞台开演前被摊开的角色档案。访客先看到一张深莓色
档案封面般的窄缎带，再进入一页冷白纸面：左侧是原创星形徽章与褪色轮廓，右侧是姓名、定位与
人物简介。往下是一次魔法道具目录、星轨章回、变身年表、技能封印与蜡封信笺。

全页只有一条档案纸与一条舞台缎带的关系，不做等尺寸卡片阵列。信息的主次由档案纸的边界、
圆形徽章、竖向星轨、深色年表栏与信封物体决定，而不是靠统一的圆角容器堆叠。

**Key characteristics:**

- **档案先行**：姓名、定位、简介始终在同一可见舞台内；没有头像时用原创轮廓、首字与星形冠冕补位，不出现空相框。
- **缎带作目录**：页眉的五个短索引沿深莓缎带排列；它们只是页内锚点，不复制共享操作菜单或语言入口。
- **星轨作章回**：项目沿一条断续的星轨展开；序号由当前数组顺序生成，只是叙述位置，不是等级、成就或完成度。
- **年表作变身**：经历在深莓栏内沿竖轴落位，period 是数据字段，不是推断的年份。
- **封印作技能**：每项技能是一枚可读的圆形封印，颜色轮换只区分节奏，不表示熟练度或稀有度。
- **信封作物件**：联系区只有邮箱或留言非空时才出现；蜡封只是装饰，正文与邮箱地址始终在可读纸面上。

## Non-goals

- 不绘制或引用任何现成动漫角色、制服、品牌标志、魔法少女作品海报或可识别的受版权保护角色。
- 不使用全屏开场遮罩、自动播放声音、循环粒子、跟随鼠标特效、Canvas 立绘或外部位图。
- 不把“章回 / 封印 / 年表”写成虚构等级、HP、XP、任务完成度、成就或用户配置。
- 不把联系方式、项目或经历补写成资料中不存在的个人事实。
- 不复制 `tape` / `archive` / `fax` / `receipt` / `poster` / `pager` 的纸张、档案盒或设备骨架。这里的是
  **舞台档案页**：封面缎带、圆形徽章、星轨、封印与信封共同承担叙事，不使用票据或手帐分页。
- 不使用通用粉色渐变、玻璃拟态或等宽网格卡片作为视觉捷径。

## Information Architecture

| 区域 | DOM / 语义 | 档案角色 | 资料字段 |
|---|---|---|---|
| 舞台页眉 | `header` + `nav` | 档案封面缎带与页内目录 | 设计文案；所有链接经 `#id` 指向实际存在的分区 |
| 首屏舞台 | `section[aria-labelledby="mg-name"]` | 开演档案与徽章 | `name`、`headline`、`bio`、`avatar?`、`location?` |
| 魔法道具 | `section[aria-labelledby="mg-links-title"]` | 悬挂在缎带上的道具目录 | `links[]` 全量；空数组显示本地化空态 |
| 星轨章回 | `section[aria-labelledby="mg-projects-title"]` | 沿星轨排布的章回 | `projects[]` 的 title / description? / url? / tags? |
| 变身年表 | `section[aria-labelledby="mg-experience-title"]` | 深色竖轴年表 | `experience[]` 的 org / role? / period? / description? |
| 技能封印 | `section[aria-labelledby="mg-skills-title"]` | 圆形封印阵列 | `skills[]` 全量 |
| 蜡封信笺 | `section[aria-labelledby="mg-contact-title"]` | 带蜡封的信纸 | `contact.note?`、`contact.email?`，两者皆空时整段不渲染 |
| 终幕 | `footer` | 舞台收束与回到开场 | 本地化 footer 文案、页内回顶锚点 |

### Field coverage

1. **核心字段**：`name` 是唯一的 `h1`；`headline` 紧随其后；`bio` 是首屏正文；`links` 每一项都渲染为
   一个真实 `<a>`，同时显示标签和压缩后的 URL 文本；已知 `icon` 值映射为电视、影片或咖啡的原创线形护符，
   其他值使用星形护符。名字、定位、简介均不从文件路径或翻译推断。
2. **可选字段**：有头像时渲染为圆形相框；无头像时渲染原创星冠轮廓与姓名首字符。`location`、`projects`、
   `experience`、`skills`、`contact` 都只在非空时条件渲染。`contact` 对象存在但两个字段皆空时也不制造空信封。
3. **非空可选内容**：项目、经历和技能按数组顺序渲染，不截断，不“仅显示前三项”。项目章节号只反映当前
   展示顺序；经历不推算时长或成就；技能不附加熟练度。
4. **URL**：链接 `href` 原样使用数据值；可见 URL 只做 `https://` / `mailto:` 前缀和末尾斜杠的显示压缩，
   不改变目标。所有站内跨页入口由框架的共享菜单负责，本设计没有自造主题切换或语言入口。

## Visual System

### Stage geometry

- 页面宽度上限 `78rem`，左右至少 `var(--mg-page-gutter)`。桌面首屏是 1 枚左侧圆形徽章 + 右侧两段文本的
  非对称网格；DOM 顺序是姓名/定位 → 徽章 → 简介，窄屏自然落成同一顺序的单列。
- 档案纸是整页最大的连续面：`2px` 墨色外框、内层发丝线、右上有纸角折页。它承载首屏，后续分区不再重复
  同一张“大卡片”，而是分别成为缎带目录、浅色章回、深色年表、封印纸面与信封物件。
- 圆弧只服务于徽章与封印；纸张边角保持宽圆角的舞台框。没有统一的 12px 卡片半径体系。
- 网点不是网格底纹：只在徽章、题头与四个局部角落出现，密度低、范围小，作为舞台印刷的装饰。

### Signature SVG assets

- **星轨**：一条主曲线 + 一条细曲线 + 三枚四角星；全部为手写 `path`，不是图标库或外部素材。
- **缎带**：首屏顶部与底部的两条宽色带及一条细线，使用原创 Bézier 曲线；色彩限制在玫瑰与浅金。
- **魔法阵**：徽章后方 360×360 viewBox 的同心圆、刻度线与星形；无文字、无符咒、无真实品牌符号。
- **半调网点**：SVG `pattern` 中的圆形点阵；作为独立装饰层，不参与用户资料的语义。
- **轮廓**：无头像时使用的星冠、肩线、四角星剪影是原创几何轮廓，不对应任何既有角色。

**Rules:**

- `Rose` 是装饰/底色色，不把 `Ink` 直接放在 `Rose` 上（实测仅 2.64:1）；联系区的标题改用 Ivory，正文放进
  Ivory Strong 信纸。
- `Gold` 是线材与纸角，不用浅金直接承担浅底小字。浅底上的金色文字统一用 `Gold Ink`。
- 装饰层的透明度不会把正文置于无底色的复杂渐变上：首屏正文在 Ivory Strong 纸面，缎带在文字后只以
  低不透明度穿过边缘；窄屏隐藏右侧文本上的大面积网点。
- 链接的 hover 不依赖颜色独自传意：每个链接保留下划线或可见边框；焦点是 3px 实线 outline。

## Typography

**Display / name / chapter titles:** Fraunces Variable Italic（`--font-fraunces`）
**CJK reading / silhouette / seal:** LXGW WenKai GB Medium（`--font-lxgw`）
**Body / UI microcopy / URLs:** Inter Variable（`--font-inter`）

### 字体选型记录（六项，依据 `docs/fonts/selection-guide.md`）

1. **隐喻与所需特征**：舞台登场档案需要一种像签名一样有收笔的展示字、一种不把长简介变成“模板正文”的
   清晰阅读字，以及一种在中文/日文封印与信纸上保持手写温度的中性字体。标题要有戏剧性但不能牺牲字形识别；
   正文要稳定；微标签要小字号可读。
2. **角色分配**：Fraunces Italic 只承担姓名、分区标题、章回标题和档案标志；Inter 承担简介、说明、URL 与
   导航微文案；LXGW WenKai 承担中文/日文展示回退、技能封印和信纸留言的中文声音。数字仍用 Fraunces/Inter
   的比例字宽，不把序号伪装成统计数字。
3. **为什么选它**：Fraunces 的斜体有较强的书写转折和 `SOFT` / `WONK` / `opsz` 可变轴，能提供“签名+印刷”
   的双重气质；LXGW WenKai 的笔画比黑体更接近注释与来信，但仍适合界面小字；Inter 在 0.72–1rem 的元信息里
   保持清晰。相对现有 `Sorts Mill Goudy`（过于古典、缺少舞台签名感）、`Prociono`（偏书页正文）、
   `UglyTypist`（手写太强、长正文不稳），这组字更贴合“档案 + 登场”而非“印刷纸物”。
4. **三语实际覆盖**：Fraunces 是拉丁展示字，不覆盖中文/日文，遇到 CJK 必须落到 LXGW 或系统字；Inter 同样
   只覆盖拉丁/西里尔等拉丁字形，CJK 必须落到 LXGW；LXGW WenKai GB 的来源覆盖为 GB2312 Hanzi `6763/6763`、
   平假名/片假名 `176/176`、JIS X 0208 `6953/6953`、ASCII `95/95`。合并六套三语文案后重生成的
   301,340 B 生产子集已复测当前页面可见文本，缺字为 0。
5. **字重、轴与许可**：Fraunces npm 字体包提供 `100–900` 可变字重与 normal/italic，以及 `SOFT` / `WONK` /
   `opsz` 轴，OFL-1.1；Inter 提供 `100–900` 可变字重、normal/italic 与 `opsz` 轴，OFL-1.1；LXGW WenKai GB
   当前使用 Medium 500、单静态字重，OFL-1.1。三者都是项目已注册的生产字体；本设计不新增字体资源或远程请求。
6. **缺失回退顺序**：
   - Display：`Fraunces Variable → LXGW WenKai GB → PingFang SC / Microsoft YaHei → Hiragino Sans / Yu Gothic UI → Songti SC / SimSun → serif`
   - Body：`Inter Variable → LXGW WenKai GB → PingFang SC / Microsoft YaHei → Hiragino Sans / Yu Gothic UI → sans-serif`
   - 手写/封印：`LXGW WenKai GB → Inter Variable → PingFang SC / Microsoft YaHei → Hiragino Sans / Yu Gothic UI → sans-serif`

### Type scale

- 姓名：`clamp(3.2rem, 7.1vw, 5.8rem)`，`0.9` 行高；中文回退到 LXGW，但保留标题字体声明中的书写顺序。
- 分区名：`clamp(2rem, 3.8vw, 3.1rem)`，行高 `1.04`，最大宽度 18ch，使用 `text-wrap: balance`。
- 正文：`clamp(0.98rem, 1.25vw, 1.08rem)` / `1.82`，限制在约 68ch；长简介不拆成逐字打印。
- 项目标题：`clamp(1.25rem, 2.3vw, 1.6rem)` / `1.25`；外链箭头是独立 SVG，不进入链接可访问名。
- 微标签：最小可见文字不小于 0.68rem；触控下通过 padding 扩大到 44px 命中，不缩小小字来“解决”空间。

## Components and States

### Keepsakes / links

- 每个 `links[]` 条目是独立的非卡片链接：圆形星符 + 标签 + 可见 URL，三项在深色缎带上共享一条目录线。
  窄屏改为纵向目录，但仍然只使用 DOM 顺序。
- 空数组：显示 `emptyLinks`，不渲染虚构道具或占位链接。
- Hover（仅 `(hover: hover) and (pointer: fine)`）：底色变为 Berry，星符轻转。键盘焦点使用 Gold Light outline，
  不依赖 hover 才能识别。

### Star-trail chapters / projects

- 每个项目有由索引派生的 `Chapter 01` 式标记、标题、可选描述与标签。星轨线只连接当前列表；没有项目时不渲染
  整个星轨区块，也不显示“完成度”。
- 有 URL 时标题本身是 44px 最小命中高度的链接，箭头作为装饰；无 URL 时标题是普通文本。
- 标签是数据标签，不再是可交互按钮；空标签数组不渲染空行。

### Transformation chronicle / experience

- 深色 Berry Deep 面板作为年表台，`period`、`org`、`role`、`description` 均按字段存在与否渲染。
- 时间线节点只是视觉定位点；没有“最早/最新”推断，也没有伪造的持续时间。
- 空经历不生成空面板。

### Sealed arts / skills

- 技能按数据顺序形成封印阵列，三项底色的轮换是节奏，不编码熟练度、等级或优先级。
- 技能文字始终可见；封印不是按钮，不添加 `tabindex`、点击或 tooltip。
- 空技能不生成面板。

### Letter under wax / contact

- 只有 `note` 或 `email` 至少一个非空时才出现。正文留在 Ivory Strong 信纸上，邮箱是至少 52px 高的真实
  `mailto:` 链接；蜡封和纸折线均 `aria-hidden`。
- 无邮箱但有留言时只显示留言；无留言但有邮箱时只显示邮箱。两者都空时不渲染联系区。

### Empty and failure states

- `links` 的空态是页面内唯一的显式空状态；其他可选区块采用“不成立则不出现”，不显示解释性空壳。
- 头像缺失不是错误态：使用原创星冠轮廓与姓名首字，首屏仍是完整档案。
- 脚本失败、无 JS、减动态时没有额外的错误提示或重试按钮；页面直接落在静态终态。

## Motion

**Motion language: “Orchestrated debut（一次开演）”**

唯一的主题动效是一次 1.06 秒内的登场编排，模拟缎带先入场、星轨随后画出、档案纸落位、魔法阵最后对齐。
它只发生在页面初始可见且 `prefers-reduced-motion: no-preference` 时，不随滚动重复，不自动循环。

| 动作 | 目标 | 参数 |
|---|---|---|
| Dossier arrival | `[data-mg-dossier]`：身份、徽章、简介 | `translateY(1.1rem)` + `opacity .78 → 1`，840ms，delay 40ms |
| Ribbon settle | 三条首屏 SVG 缎带 | `translateX(-1.4rem)` + opacity，920ms，delay 40ms |
| Star-trail draw | 两条 `[data-mg-trail]` | `strokeDashoffset 1 → 0`，1000ms，delay 20ms |
| Magic-circle alignment | 徽章后魔法阵 | `rotate(-18deg) scale(.97)` → `rotate(0) scale(1)`，1040ms，delay 20ms |

**Contract:**

- 总时长最长 **1060ms**（1040 + 20），不超过 1.2 秒。
- 内容 HTML 默认就是最终可读态；Web Animations 的终帧与自然 CSS 终态相同，不使用会固化的
  `fill: forwards`，无 `@keyframes` 隐藏门控，无 overlay / dialog / backdrop。
- `script.ts` 只在 `document.visibilityState === 'visible'` 且非减动态时初始化。初始化后仅注册一次性的
  `visibilitychange` 与媒体查询变更监听；动画完成、页面被隐藏或用户切到减动态时统一 `finish` 并移除监听。
- 不使用 `requestAnimationFrame`、`setInterval`、音频、滚动监听或持续粒子；脚本不 import CSS、无依赖、单一入口。
- 减动态：脚本不启动，CSS 只禁用过渡；所有元素保持终态。无 JS / 模块加载失败 / 初始化抛错：没有脚本门控，
  HTML 与样式本身完整可见。动画中途失败：`catch` 只做 `finish` 与清理，不写入任何隐藏内容的状态。

## Responsive Layout

- **≥62rem**：首屏为左侧徽章、右侧身份与简介；章回/年表为 1.5 : 0.82 双列，技能/信笺为 1.14 : 0.86 双列。
- **<62rem**：首屏按 DOM 单列（身份 → 徽章 → 简介），章回、年表、技能、信笺依次单列；双列只属于桌面。
- **<46rem**：页眉索引换行成窄缎带；首屏内边距和圆角收敛；封印改为两列；章回标记缩窄但不隐藏语义。
- **≤22rem**：进一步缩小索引与章回标记的横向占用，星符和链接命中高度仍保持可触控。
- 所有网格子项 `min-width: 0`；长 URL、姓名、项目标题允许换行；页面 `overflow-x: clip` 也不代替内容宽度约束。
- 固定或绝对装饰只出现在局部区域的 `overflow` 内，不生成横向滚动；正文列在 1440 / 1280 等常用桌面宽度都有
  `78rem` 最大宽度与可见左右留白。

## Accessibility

- `HeadMeta` 原样接收 `view.head`；`html lang` 使用 `view.head.lang`；共享 `ContextMenu` 是无条件唯一的操作/语言入口。
- 每个 section 通过 `aria-labelledby` 指向同区可见 `h2`（首屏指向唯一 `h1`）；页眉 nav 有本地化
  `aria-label`，footer 有本地化 `aria-label`。标题层级为 `h1 → h2 → h3`，项目/经历条目为 `h3`。
- 单页页眉目录只链接实际渲染的分区；条件区块缺失时对应锚点同时消失，不保留死链。
- 装饰 SVG、网点、魔法阵、轮廓、星符、箭头、蜡封和折页都 `aria-hidden="true"`；所有链接的可访问名以文本
  标签或数据标题开始，不以装饰字符开头。
- 头像有相邻姓名作为可访问身份，因此图片使用空 alt；无头像的轮廓是装饰，不朗读“占位图”。
- 所有交互链接有可见焦点：浅底 3px Ink outline / 深底 3px Gold Light outline，偏移 4px；不隐藏 outline。
- 触控命中：页眉索引 ≥44px、项目标题链接 ≥44px、邮箱 ≥52px（coarse 提升至 56px）、回顶 ≥44px。
  技能封印和标签不是交互元素，不赋予虚假按钮语义。
- `prefers-reduced-motion: reduce` 下不启动主题脚本，CSS 过渡压缩到 0.01ms；内容不依赖悬停，不做键盘路径
  之外的焦点陷阱。

## Original Assets and Provenance

- `design.json` 的 `source.type` 是 `self-produced`，没有外部规范快照、品牌字体或第三方角色素材。
- 页面与预览中的星轨、缎带、魔法阵、半调网点、轮廓、星符和箭头全部为本次手写的内联 SVG / CSS 几何；

## JavaScript Boundary and Budget

- 唯一入口：页面末尾的 Astro 处理模块 `<script>import './script';</script>`，私有文件 `script.ts`。
- 用途仅是一次性入场编排；它不获取数据、不改文案、不切换面板、不拦截键盘或滚动，也不改变任何链接目标。
- 零依赖、无 CSS import、无第三方交互包、无 `requestAnimationFrame`、无音频、无覆盖层、无无限循环。
- 形式化静态测量（Rolldown 1.2.13，minify，ESM，browser）：源码 bundle **1,536 B raw / 645 B gzip**，
  远低于 12KB gzip 上限。最终集成页应重新按页面独立 chunk 复测，静态测量不能替代构建产物检查。
- 初始化失败、模块加载失败、无 JS、减动态与页面初始不可见均直接使用静态终态；脚本不建立内容可达性的前提。
