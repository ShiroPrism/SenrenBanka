# HTML Only — 原生 HTML 渲染契约

## 设计意图

这套设计不模拟任何视觉风格。页面本身就是设计对象：一份可被浏览器、搜索引擎、读屏器与纯文本工具直接理解的原生 HTML 文档。

它用于证明同一份个人资料可以脱离自定义样式与脚本，仍完整保留信息层级、导航、语言切换与联系路径。浏览器默认的字号、行距、列表标记、链接颜色和焦点轮廓不是待替换的占位样式，而是这套设计的最终呈现。

## 资源契约

- 正式页交付物仅 `DESIGN.md`、`design.json`、`Page.astro`、`messages.ts`。
- 不提供 `style.css`、`tokens.css`、私有组件或视觉素材。
- 可选 `Preview.astro` 仅用于切换页，样式完全自包含，不 import 正式页 CSS，也不进入正式页产物。
- 页面不渲染 `Font`、`Reveal`、`ContextMenu`、`InfraStyles` 或 `LanguageSwitcher`。
- 最终 HTML 不包含 `<style>`、`style` 属性、`<script>`、事件处理器、`iframe` / `object` / `embed`、样式表、预加载链接、`javascript:` URL 或 meta refresh。
- `<link>` 只允许站点 metadata 所需的 `canonical`、`alternate`、`icon`。

## 语义结构

1. `<header>`：姓名（唯一 `h1`）、headline、可选所在地与 bio。
2. `<nav>`：页内目录、同主题语言链接，以及 `manualSwitch: true` 时的全部设计链接。
3. `<main>`：核心链接；存在数据时依次呈现项目、经历、技能与联系。
4. `<footer>`：回到页面顶部。

每个内容分区使用可见 `h2` 与 `aria-labelledby`；项目与经历条目使用 `h3`。目录只列出实际存在并拥有锚点的分区。

## 内容取舍

- 核心字段 `name` / `headline` / `bio` / `links` 全部渲染。
- 可选字段 `location` / `projects` / `experience` / `skills` / `contact` 全部渲染；不因视觉精简而丢弃数据。
- `avatar` 不渲染。无样式的原始图片尺寸不可控，且头像不承载唯一的身份信息；姓名与简介已完整承担身份表达。
- 项目标题、描述、链接和标签，经历的组织、角色、时间与描述，以及联系的邮箱和说明均原样保留。

## 字体与色彩

不选择字体、不声明字体族、不加载字体资源。排版完全采用浏览器的用户默认值，因此会尊重用户的字号、缩放、强制颜色与可访问性设置。

不设置调色板。正文、链接、已访问链接、选区与焦点状态全部采用浏览器原生语义色。设计不通过颜色或装饰表达额外状态。

## 布局与图标

不设置栅格、间距、圆角、边框或断点。文档保持浏览器默认的单列流式布局，在 320px 至桌面宽度下自然换行。

不使用图标库、内联 SVG、ASCII 装饰或品牌标记。链接文本本身承担可访问名称，避免图形成为额外信息层。

## 动效（Motion）

本设计**决定完全静止**。没有入场动画、滚动显现、持续动画或自定义交互过渡。

理由：该模式验证的是内容在没有 CSS 与 JavaScript 时的原生可读性。若再加入动画，就必须引入样式或脚本，直接破坏主题的定义。浏览器原生的锚点跳转、焦点环与滚动行为不受此决定限制。

## 无障碍

- 文档语言来自 `view.head.lang`；语言链接同时标注 `hreflang` 与 `lang`。
- 当前语言以 `aria-current="page"` 标识。
- 每个 `<section>` 有可访问名称；标题层级从 `h1` 到 `h2` / `h3`。
- 所有导航都是普通链接，不依赖 hover、指针、JavaScript 或隐藏菜单。
- 无自定义颜色、字号与对比度覆盖；呈现遵循浏览器与用户设置。

## 切换页预览

`Preview.astro` 是一枚自包含的“原生文档”缩略引述：白色纸面、浏览器默认的衬线排版、标题层级、目录与普通蓝色链接。它只使用真实姓名、headline、导航标签与前三条链接，不引入 `style.css`、`tokens.css`、`<Font>`、可聚焦元素或动画。

预览的样式只存在于切换页聚合 CSS 中；正式 HTML-only 页面仍然没有样式表、内联样式或脚本。预览不是“模拟无样式”的截图，而是该主题在切换页中的视觉签名：读者应一眼看出它是一份未加页面样式的普通 HTML 文档。
