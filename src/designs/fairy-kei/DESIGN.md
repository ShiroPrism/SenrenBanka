# Fairy Kei — 打开的复古玩具收藏盒

> 来源：`self-produced`。本文件是该设计的视觉规范与实施记录；规则正文仍以
> `docs/rules/` 为准。实施日期：2026-10-29。

## 1. 隐喻与边界

页面不是“粉色卡片主页”，而是一只放在浅色工作台上的复古少女玩具收藏盒：
盒盖向内翻开，露出一块 mint 色绒面陈列区；中央是姓名牌与拱形收藏窗，饰品沿
金色横链悬挂，说明卡、玩具抽屉、丝带卷轴、贴纸册和便签分别占据盒内不同隔层。

视觉签名：

- 打开的盒盖有糖果条纹、双缎带、封签与铆钉。
- 盒身是层叠几何，不是统一圆角卡片：硬描边、错位硬影、切角包装纸、抽屉拉手、
  圆形铆钉与一枚底部锁扣共同建立“物件”。
- 主色为 cream / mint / butter，rose、peach、lilac、blue 只作为分格与吊饰色块；
  页面不铺满单一粉色。
- 不使用心形、Emoji 堆叠、贴纸散布替代布局，也不使用 Sticker Diary 的跨页纸本
  结构或 Tape / Archive 的桌面纸片陈列。

非目标：

- 非通用 kawaii 卡片流；所有分区必须像盒内不同隔层。
- 非手帐跨页；没有书页编号、装订轴或翻页交互。
- 非海报 / 档案 / 收据的单一纸张平面。
- 不新增人物事实、收藏编号含义、等级、进度或虚构成就。

## 2. 信息架构与字段映射

DOM 与移动端视觉顺序一致：

| 顺序 | DOM / 可见分区 | 字段 |
|---|---|---|
| 1 | 打开的盒盖 | 装饰性盒名；`aria-hidden` |
| 2 | 中央收藏窗与姓名牌 | `avatar`（可选）、`name`、`headline`、`location`（可选） |
| 3 | 悬挂饰品链 | `links[].label` 与真实 `links[].url` |
| 4 | 包装说明卡 | `bio` |
| 5 | 玩具抽屉 | `projects[].title / description / url / tags`，每个非空子字段条件显示 |
| 6 | 丝带卷轴 | `experience[].org / role / period / description`，每个非空子字段条件显示 |
| 7 | 贴纸册 | `skills[]` |
| 8 | 便签 | `contact.email` / `contact.note`；两项都为空时不渲染该分区 |
| 9 | 收藏卡背面 | 设计收尾句、品牌与可选站点声明；不承载个人事实 |

- `name / headline / bio / links` 始终存在；`links` 为空时显示诚实的空态。
- `avatar` 缺失时保留完整拱形窗口与 CSS 收藏徽章，构图不塌陷。
- 头像直接使用数据层已解析的 `ImageMetadata` 或外部 URL，不自建图片管线。
- 所有项目抽屉默认 `open`：无 JavaScript 时全部真实内容立即可读；用户可用原生
  `details / summary` 自行收回。无链接的项目不显示 CTA。
- 页面不渲染 `<LanguageSwitcher>`；语言与主题切换只由末尾共享 `ContextMenu` 承担。

## 3. 视觉系统

### 桌面骨架

- 内容宽 `min(76rem, 100%)`，外框保留明显的桌面左右留白。
- 12 栏不对称陈列：说明卡 5 栏、玩具抽屉 7 栏；丝带卷轴 7 栏、贴纸册 5 栏；
  便签居中占 8 栏。首屏身份区是 7:5 的姓名牌 / 收藏窗关系。
- 各隔层不是同一卡片模板：包装卡使用切角，项目是带拉手的抽屉，经历是带圆章
  的竖向丝带，技能是贴纸，联系是折角便签。

### 调色板

令牌唯一定义在 `tokens.css`，作用域为 `:is(.fk, .fk-pv)`，无 `:root`。

| 令牌 | 色值 | 用途 |
|---|---|---|
| `--fk-cream` | `#fff1cf` | 工作台暖底 |
| `--fk-room` | `#f3dfba` | 工作台渐深 |
| `--fk-paper` | `#fff9ec` | 标签 / 正文纸面 |
| `--fk-mint` / `--fk-mint-soft` | `#ccebdd` / `#e7f7ef` | 盒内绒面 |
| `--fk-butter` | `#ffe39b` | 姓名牌 / 接触便签 |
| `--fk-rose` | `#f3adc4` | 盒盖条纹 / 丝带 |
| `--fk-peach` | `#ffc4ad` | 抽屉与折角 |
| `--fk-lilac` | `#ddcff0` | 饰带 / 贴纸 |
| `--fk-blue` | `#aedee8` | 包装线 / 收藏窗 |
| `--fk-ink` | `#2c2138` | 正文 / 主描边 |
| `--fk-ink-soft` | `#5a4c68` | 次级文字 |
| `--fk-plum` | `#753956` | 小标签 / 印章 |
| `--fk-coral` | `#b74852` | 图钉 |

几何规则：主盒描边 3px，内部物件 2px；偏移硬影不超过 0.65rem，软影只用于盒身
与悬浮物；圆角只用拱形窗口、胶带、贴纸和抽屉拉手等各物件自身的形态，不把所有
分区统一成圆角卡片。

## 4. 字体与六项记录

1. **隐喻与字体特征**：玩具收藏盒需要三声部——盒面糖果字、收藏者的手写声部、
   清晰可读的说明文字。标题要圆、厚、像压模字母；阅读文字不能牺牲比例。
2. **角色分配**：标题 / 分区名 / 编号使用 Fredoka，缺字落到 LXGW；正文、网址、
   表单式元信息使用 Inter；中日文手写尾链（贴标、便签正文）使用 LXGW WenKai。
3. **取舍理由**：Fredoka 的圆润几何来自真实字体文件样张，能承担复古玩具包装的
   展示角色而不滑向通用无衬线；LXGW 提供手写感的简中 / 日文字部；Inter 维持长
   段落和高密度元信息的阅读稳定。没有为“显得丰富”再加入第四族。
4. **实际覆盖与回退**：Fredoka latin 文件覆盖 ASCII 95/95、Latin-1 字母 62/62，
   GB2312 0/6763、假名 0/176，因此英文标题直接命中，中日文必须落到 LXGW 或系统
   CJK。LXGW GB 完整源覆盖 GB2312 6763/6763、假名 176/176、JIS X 0208 6953/6953、
   常用 CJK 标点 53/53；外部 catalog v1.0.0 提供完整 `core-cjk` cmap（328 个
   `unicode-range` 分片，家族包 13,841,062 B），不再依赖六套文案合并后的站内子集。
   Inter 覆盖拉丁正文，CJK 只作回退。
5. **字重、轴与许可**：Fredoka Variable 为 wght 300–700，latin 29,784 B +
   latin-ext 4,576 B，OFL-1.1；LXGW WenKai GB Medium 为 500，完整分片由外部
   catalog v1.0.0 锁定，OFL-1.1；Inter 复用站点现有 variable 依赖。字体许可文件随
   外部家族包归档，本设计不复制或改写许可。
6. **缺失回退顺序**：展示 = Fredoka → LXGW → PingFang SC → Microsoft YaHei →
   Hiragino Sans → Yu Gothic UI → sans-serif；正文 = Inter → LXGW → PingFang SC →
   Microsoft YaHei → Hiragino Sans → Yu Gothic UI → sans-serif；手写标签 =
   LXGW → Fredoka → 同一条系统 CJK / sans-serif 尾链。断网或无字体时版式仍可读。

字体角色只在 `style.css` 的 `@theme inline` 注册，不在 `tokens.css` 重复。

## 5. 组件与状态

- **收藏窗**：拱形硬框 + 双层纸边 + 铆钉；有头像时 `object-fit: cover`，无头像时
  显示原创 CSS 星形徽章。头像替代文本由主题文案模板与真实姓名组成。
- **饰品**：`ul` 中每条真实链接是一个吊牌；链线和序号为装饰。整卡可点，最小高度
  44px；窄屏单列，不依赖 hover。
- **项目抽屉**：原生 `details[open]`，`summary` 承担项目标题与开合；项目内 CTA
  只在真实 URL 存在时出现。没有脚本门控。
- **丝带卷轴**：经历圆章与卡片挂在同一条 CSS 丝带上；圆章编号只表示呈现顺序。
- **贴纸册**：技能是轮换边线和底色的贴纸，仍按语义列表读取。
- **便签**：折角纸面与图钉均为装饰；邮箱是真 `mailto:` 链接。
- **焦点**：浅色面上使用 3px 深色轮廓；深色 CTA 与跳转链接反转成纸色轮廓加
  深色外环。所有交互都有 `:focus-visible`。

## 6. 动效

主题没有私有 JavaScript。一次开盒编排全部由 CSS 完成：

- 盒身下落 640ms；盒盖从 17° 回弹到 7° 历时 740ms；收藏窗以 0.95 → 1 的缩放
  落位 720ms；饰品以 50ms 步进逐枚静止，最后一枚在 760ms 内结束。
- 全部关键帧只改变 `transform`，不使用会把未推进动画固化为不可见终态的
  `forwards / both`；减动态时不生成任何动画与过渡。
- 下半页采用共享 `<Reveal />`：内容默认可见；隐藏态只用
  `html[data-reveal-ready] .fk [data-reveal]` 门控，进入视口后一次显示。无 JS、
  无 IntersectionObserver、脚本失败或减动态时保持自然可见。
- hover / focus 只做一次小幅摆动或按压回弹；没有无限循环、滚动劫持或鼠标跟随。

## 7. 响应式与无障碍

- `>64rem`：12 栏不对称陈列。
- `<=64rem`：8 栏两区陈列，说明卡与抽屉、丝带与贴纸仍保持阅读顺序。
- `<=48rem`：全部回到 DOM 单列；饰品单列、项目单列，盒盖缩为 7.8rem 高。
- `<=22rem`：隐藏抽屉右侧拉手，缩短圆章列宽，避免 320px 横向溢出。
- 页面、语言、链接与项目标题均允许 `overflow-wrap: anywhere`；内部网格使用
  `minmax(0, 1fr)`。装饰盒盖 / 铆钉不会进入可访问名。
- 每个分区由可见 `h2` 与 `aria-labelledby` 命名；项目、经历、技能与标签使用列表
  语义；装饰元素带 `aria-hidden`。
- 链接、`summary`、邮箱和跳转链接命中高度至少 44px（`pointer: coarse` 显式声明）。
- 键盘路径：跳转链接 → 共享菜单前的饰品链 → 原生 `details` 抽屉 → 项目 CTA →
  邮箱。没有焦点陷阱。

| 前景 / 背景 | 对比度 |
|---|---:|
| `#2c2138` / `#fff9ec` 正文纸面 | 14.48:1 |
| `#2c2138` / `#fff1cf` 暖底 | 13.56:1 |
| `#2c2138` / `#ccebdd` 盒内绒面 | 11.94:1 |
| `#2c2138` / `#ffe39b` 便签 | 12.10:1 |

`--fk-ink-soft`，不使用浅色小字压在 rose / mint 上。

## 8. 预览碎片

- 画幅：切换页的 16:10 预览容器内铺满，最小高度 9rem。
- 只保留视觉签名：条纹开盖、中央收藏窗、Fredoka 姓名牌、两枚真实链接吊牌和
  底部锁扣；不复制完整页面、不带动效、不出现 CTA。
- 自包含 `<style>`；不 import `style.css`，不声明 `<Font>`，令牌只来自
  `tokens.css`，无可聚焦元素；导出 `--font-fredoka` / `--font-lxgw` /
  `--font-inter` 给切换页按族去重。
- 缩略档位：类型 0.29–1.55rem、2px 主描边、0.12–0.28rem 硬影、0.12–0.75rem
  圆角。它们只属于预览比例，不回写正式页令牌或排版阶梯。
