# Deco — Art Deco 剧院节目单

> **来源**：自产（`self-produced`）。本规范先于实现；实现与规范不一致时先改规范。
>
> **一句话**：把个人资料做成一张 1920 年代剧院的**夜场节目单**——墨黑台面、黄铜双线框、金色扇形与阶梯角、Didone 衬线的对称版式；台词（正文）永远是米白，金色只留给标题与装饰。

## 1. 设计隐喻

不是复古壁纸，也不是霓虹赛博。它是**剧院散场后还亮着的售票厅**：节目单、幕次、演职员表、当日券売所。所有信息都像印在一张对折的铜版纸上——有边框、有编号、有对称的页眉页脚。

由此导出三条硬约束：

1. **对称优先**：中轴构图、成对装饰（左右扇形/双线框/菱形），任何信息块都居中或成对出现。
2. **金只发声，不叙述**：金色承担「被照亮的金属」职责，只出现在标题、编号、装饰线与焦点环；正文永远米白，保证长时间阅读不刺眼。
3. **线框即秩序**：信息层级靠**发丝线**（1px）与**双线框**（1px + 内缩 1px）表达，不靠色块堆叠；页面底色只有一档黑，场次靠框线分隔。

**用色规则（强制）**

- 正文 / 描述 / 表格说明**只用** `--dc-ivory` 或 `--dc-ivory-soft`；弱化元信息用 `--dc-muted`。三者全部 ≥7.5:1。
- `--dc-gold` **只用于**标题（h1/h2/h3 展示位）、幕次编号、monogram、装饰线与菱形、`≥1.25rem` 的售票处链接；**不得用于正文段落**。
- 小号标签（0.66–0.72rem）用 `--dc-gold-bright`（香槟米金，15.41:1），不用饱和金，避免小字号发脏。
- `--dc-brass` / `--dc-hairline` 只画线与框，不作文字色（5.52:1 / 3.86:1，均满足非文字 3:1）。
- 金色不得压在米白或金色上（`--dc-gold` on `--dc-ivory` 仅 1.85:1，永不使用）。
- 任何新增色值必须先算对比度、登记本表，再进 `tokens.css`。

## 3. 字体（六项记录）

### 3.1 隐喻与字体要表达的特征

节目单是**印刷品**：展开发亮的铜版纸、Didone 的高对比笔画、宽字距的全大写、编号对齐。标题要「被灯打亮的金属」，正文要「在暗处仍然清楚」，中文要能与衬线英文混排而不塌成黑块。

### 3.2 角色分配

| 角色 | 拉丁主 face | CJK |
|---|---|---|
| 展示（姓名 / 分区标题 / 幕次编号 / monogram / 售票处链接） | Fraunces Variable | Zhuque Fangsong |
| 正文（headline / bio / 描述 / 标签 / 页脚） | Inter Variable | Zhuque Fangsong |

- 数字与编号：走展示角色（Fraunces），罗马数字 I–XII 作为幕次序号；不需要等宽体，因为编号是单点装饰而非表格对齐。
- 只用两套拉丁字体，不引入第三套「技术标记」字体：节目单的元信息用 Inter + 宽字距 + 全大写即可，加等宽体会变成票据而不是节目单。

### 3.3 为什么是它们（而非其他候选）

- **Fraunces Variable**：可变 `opsz` 轴到 144，正好给出 Didone 需要的高对比发丝衬线；`SOFT` / `WONK` 轴默认 0 时笔画干净、不花。项目已有的 `Sorts Mill Goudy` / `Prociono` 是旧式衬线，笔画对比不足，撑不起金框大字；新增候选（受许可与体积门禁约束）不必要——复用现有生产 family 已能满足隐喻。
- **Inter Variable**：暗底下的小字号与长段描述稳定、字形中性，不与 Fraunces 抢戏；信息密度高的演职员表/标签同样成立。
- **Zhuque Fangsong**：项目现有核心 CJK 中唯一带书写与纸张气质的仿宋体，与「印刷节目单」同源；单字重（400）刚好匹配本设计克制的字重策略。
- 未新增任何字体资源：全部为已启用、已过许可闸门的生产 family。

### 3.4 实际覆盖（简中 / 日 / 英）

| face | 英文 / ASCII | 简体中文 | 日文 |
|---|---|---|---|
| Fraunces Variable（latin 子集 U+0000–00FF 等） | 可打印 ASCII 95/95 全覆盖 + Latin-1 | 0（落 `--font-zhuque`） | 0（落 `--font-zhuque`） |
| Inter Variable（latin 子集） | 可打印 ASCII 95/95 全覆盖 + Latin-1 | 0（落 `--font-zhuque`） | 0（落 `--font-zhuque`） |
| Zhuque Fangsong（161 分片，12,882 码位） | 可打印 ASCII 95/95 | GB2312 汉字 **6763/6763（100%）** | 假名区 U+3040–30FF 覆盖 **181/192**；缺的 11 个码位为 `U+3040`（未分配）、`U+3095–U+3098`（小假名）、`U+309B–U+309C`（浊点/半浊点独立码位）、`U+309F`（ゟ）、`U+30A0`（゠）、`U+30FE–U+30FF`（ヾ/ヿ），均属未分配或罕用字符 |

- 三份资料文案（含中日混排的 bio、日文标点）落在 Zhuque 覆盖范围内；阿拉伯数字与拉丁词先由 Fraunces / Inter 命中。
- 源字体缺字（非 GB2312 罕用字）时按 3.6 的顺序回退到系统中文，版式不依赖字体加载成功。

### 3.5 字重 / 可变轴 / 体积 / 许可

| face | 字重 | 可变轴 | 体积（latin wght 单文件） | 许可 |
|---|---|---|---|---|
| Fraunces Variable | 400（展示位统一 400，靠 `opsz` 自动光学尺寸） | `wght` 100–900、`opsz` 9–144、`SOFT` 0–100、`WONK` 0–1、`ital` | 36,620 B（`fraunces-latin-wght-normal.woff2`） | OFL-1.1 |
| Inter Variable | 400 / 500（标签 500，正文 400） | `wght` 100–900、`opsz` 14–32、`ital` | 48,256 B（`inter-latin-wght-normal.woff2`） | OFL-1.1 |
| Zhuque Fangsong 1.0.0 | 400（单字重） | 无（静态） | 5,998,018 B 打包分片，构建期按页面语料子集 + 裁剪 | OFL-1.1（无 Reserved Font Name） |

- 本设计不写 `@font-face`，不加 `font-variation-settings` 以外的轴调参（`opsz` 交给浏览器自动光学尺寸）。
- 体积策略：装饰全靠 CSS（扇形渐变、菱形、双线框），本设计**不新增任何图片资源**。

### 3.6 缺失回退顺序（完整栈由本设计 CSS 拥有）

```
展示：var(--font-fraunces), var(--font-zhuque), "Songti SC", "SimSun", "Hiragino Mincho ProN", "Yu Mincho", serif
正文：var(--font-inter), var(--font-zhuque), "PingFang SC", "Microsoft YaHei", "Hiragino Sans", "Yu Gothic UI", sans-serif
```

- 顺序恒为「拉丁主 face → Zhuque → 系统中文 → 系统日文 → 通用族」；系统 CJK **永不**排在 `var(--font-zhuque)` 之前。
- 正式页的栈定义在 `.deco`（`--dc-type-display` / `--dc-type-body`）；预览在 `.deco-pv` 内自带同序栈。两处受同一 `npm run fonts:typography` 门禁。
- `--font-*` 只暴露主 face（`fallbacks: []` + `optimizedFallbacks: false`），系统字体只出现在设计 CSS。

## 4. 版式

- **画幅**：内容轴宽 `66rem`（`--dc-max`），桌面左右留白 `clamp(1.15rem, 4.5vw, 3.5rem)`（`--dc-pad`）——1280–1536px 下可见留白充足，内容不贴边。
- **背景**：`--dc-black` + 顶部一枚极淡金色径向辉光（`rgb(212 175 55 / 0.10)`，38rem × 22rem，中心在页面上缘）+ 5px 间隔的 1.8% 米白竖纹（印纸质感）。二者只做氛围，不参与信息层级。
- **页眉（masthead）**：双发丝线（`border-top` + `border-bottom`，1px，间隔 6px）→ 轴心一行「菱形 — 地名 — 菱形」（缺 `location` 时回退为节目单标签），香槟金色、0.22em 字距、全大写。
- **首屏（hero）**：扇形放射（`repeating-conic-gradient`，7° 一束）→ 节目单 kicker（0.42em 字距）→ monogram 菱形双框 → `h1` 姓名 → headline 副题 → 菱形分隔线 → 序言块（上下发丝线的引言区，内文左对齐以提高可读性）。左右上/下角为阶梯角装饰（`clip-path` 三阶 L 形）。
- **分区**：四个 `h2` 区块（剧目表 / 幕次 / 演出单 / 演职员表）+ 一个售票处面层；每个分区以 1px 上边线开场，标题居中、`0.16em` 字距，标题下是一条「线—菱形—线」分隔。
- **分区顺序即节目单顺序**：先剧目表（链接），再幕次（projects），再演出单（experience），再演职员表（skills），最后售票处（contact）。
- 网格：幕次 3 列（>1024）→ 2 列（≤1024）→ 1 列（≤760）；演职员表 3 列 → 2 列 → 1 列（≤640）。

## 5. 组件

- **monogram**：`clamp(3.4rem, 9vw, 4.8rem)` 正方形，外框 1px 金菱形 + 内框 1px 黄铜菱形（`inset: 5px`），中心为姓名取首构成的 2 字标记（拉丁取词首字母 `KT` / `TK`，CJK 取前两字 `田所`）。标记整体 `aria-hidden`，**完整姓名始终作为 `h1` 文本渲染在其下方**。
- **票根链接（剧目表）**：`min-height: 48px` 的框，`--dc-panel` 底 + 1px `--dc-hairline` 外框 + 内缩 4px 的 1px `--dc-brass` 内框；左端 6px 金菱形。hover（仅 `(hover: hover) and (pointer: fine)`）时外框转金、文字提亮到 `--dc-gold-bright`、菱形放大 1.25。
- **幕次卡**：`--dc-panel → --dc-panel-2` 竖向渐变、1px 框、左上阶梯角（1.6rem，`--dc-brass`，55% 不透明）；顶部罗马数字（金），标题居中，描述 `--dc-ivory-soft`，标签行以发丝线分隔、每项前置 4px 黄铜菱形。
- **演出单（bill）**：两列（机构/角色 ←→ 期间）行式台账，1px 行分隔；机构用展示字体（米白），角色 `--dc-muted`，期间用香槟金 0.2em 字距右对齐（≤760px 转左对齐），描述跨两列。
- **演职员表（credits）**：3/2/1 列列表，每项左端一枚 5px 空心黄铜菱形。
- **售票处（box office）**：带双线框与上下渐隐底色的面层；邮件链接为金、展示字体、`clamp(1.25rem, 3vw, 1.6rem)`、`min-height: 48px`；备注为 `--dc-muted`。
- **页脚**：1px 上边线 + 菱形分隔 + 姓名（展示字体、0.14em 字距）+ 可选站点声明（0.22em 字距全大写）。
- **装饰件**（全部 `aria-hidden`）：`.dc-fan` 扇形、`.dc-ornament` 线—菱形—线、`.dc-step` 阶梯角、`.dc-monogram-gem` 菱形双框、卡内菱形/编号。无一进入可访问名。

## 6. 动效（Motion）

**动效语言**：幕布拉开的一次性仪式感——金色细线「拉直」、扇形「展开」、幕布向两侧分开；之后页面完全静止，只有交互态的短促颜色过渡。

| 动作 | 形态 | 参数 | 播次 |
|---|---|---|---|
| 幕布分开 | 两半幕布以 `scaleX(1) → scaleX(0)` 向左右退场（`transform-origin: left / right`） | 900ms，`cubic-bezier(0.33, 0, 0.2, 1)` | 一次 |
| 扇形展开 | 放射扇形 `opacity 0 → 1`、`scale(0.94) → 1` | 700ms，同缓动 | 一次 |
| 金线拉直 | 分隔线与页眉线 `scaleX(0) → scaleX(1)` | 620ms，同缓动 | 一次 |
| 首屏升起 | kicker / monogram / 姓名 / 副题 `translateY(10px) → 0`（**只动 transform，不动 opacity**） | 520ms，`cubic-bezier(0.2, 0.7, 0.2, 1)` | 一次 |
| 滚动显现 | 共享 `Reveal`：分区与幕次卡 `data-reveal`，`opacity + translateY(14px)`，卡按 70/140ms 错落 | 240ms（`--dc-dur`） | 每元素一次 |
| 交互 | 框线/文字颜色 220ms；菱形 `transform: rotate(45deg) scale(1.25)` | 220ms | 交互时 |

- 全部关键帧包在 `@media (prefers-reduced-motion: no-preference)`；关键帧**不使用 `both` / `forwards`**，元素的静态基态就是终态或完全隐藏态（幕布基态 `scaleX(0)`、扇形基态不透明 1、文字基态无位移）——因此动画未推进时不会有内容被错误隐藏。
- 唯一以隐藏态为基态的是**装饰性幕布**（`aria-hidden`、无内容、不承载交互）；它若静止不动视觉上等同于「已经拉开」。
- 隐藏门控只有 `html[data-reveal-ready]`（由共享 `Reveal.astro` 在非减动态且支持 `IntersectionObserver` 时写入）。无 JS / 无 IO / IO 抛错 / 减动态 → 该属性不存在 → 内容全部可见。
- 无设计专属 JS、无无限循环、无滚动劫持、无光标替换、无自动播放声音。

## 7. 响应式

| 视口 | 行为 |
|---|---|
| ≥1440px | 内容 66rem 居中；幕次 3 列；演职员表 3 列；扇形 15rem；姓名字号上限 5.2rem |
| 1024–1440px | 同上，留白随 `clamp()` 收缩 |
| 768–1024px | 幕次 2 列、演职员表 2 列；扇形 24vw；姓名 8.4vw |
| ≤760px | 幕次 1 列；演出单折为单列（期间左对齐）；正文 16px |
| ≤640px | 演职员表 1 列；阶梯角缩到 1.6rem；序言块内边距收紧 |
| 375×812 | 姓名 `clamp(1.9rem, 9.5vw, 2.6rem)`；票根链接整行；kicker 字距降到 0.3em；**无横向溢出**；长 URL / 长词 `overflow-wrap: anywhere` |

- 对称构图在窄屏降级为单列，但**双线框、菱形分隔、阶梯角、金线语言全部保留**——降级的是列数，不是装饰语法。
- 触控（`pointer: coarse`）：票根链接 ≥48px、售票处链接 ≥48px、幕次标题链接 ≥44px；hover 效果一律由 `(hover: hover) and (pointer: fine)` 门控，触屏不依赖 hover。

## 8. 无障碍

- `h1` 只有姓名一处；层级 `h1 → h2 ×5 → h3 ×N`（幕次标题），不跳级。
- 每个 `<section>` 都用 `aria-labelledby` 指向同区可见标题（首屏指向 `h1` 的 id）。
- 所有装饰（扇形、分隔菱形、阶梯角、monogram 菱形与字母、幕次编号、标签菱形、票根菱形）`aria-hidden="true"` 或纯伪元素；链接可访问名只由文本标签承担。
- 焦点：`:focus-visible` 为 2px `--dc-gold-bright` 实线 + 3px offset（黑底 15.41:1、面2 13.84:1）；框内链接同样可见。
- 对比度：正文/描述 ≥7.5:1，标题（金）≥8.6:1，非文字线条 ≥3.4:1（见第 2 节全表）。
- 键盘顺序 = DOM 顺序；无 `tabindex` 把戏；无 `hidden` 焦点残留。
- 选区内文字反色为黑 on 金（9.61:1）。
- 语言切换由共享操作菜单承担，页面不渲染 `<LanguageSwitcher>`。

| `contact` | 售票处（邮件链接 + 备注） | 条件渲染；email 与 note 都不存在时整块不渲染 |
| `avatar` | **不呈现** | 节目单是印刷字体页；加头像会破坏「无图片、纯 CSS 装饰」的取舍，且避免头像管线的裁切差异 |
| `location` | 页眉 meta 行（缺失时回退为节目单标签） | 不虚构地名 |
| `links[].icon` | **不呈现** | 本设计不引入图标语言，只用菱形与框线；图标会分散 deco 语法 |

- 条件区块为空数组或缺失时**不渲染空外壳**（不出现空标题、空框、空列表）。
- 页脚只有「完整姓名 + 可选站点声明」，不倒推任何事实。

## 10. Do / Don't

### Do

- Do 让中轴对称贯穿全页：页眉标记、首屏、分区标题、页脚都在中轴。
- Do 用 1px 发丝线与内缩双框表达层级；边框是这套设计的骨架，比色块更重要。
- Do 把金色留给标题、编号、装饰与焦点环；正文永远米白。
- Do 在窄屏保留双线框、菱形与阶梯角语言，只把列数降到 1。
- Do 让每个装饰件 `aria-hidden`，让可访问名只由文本承担。
- Do 复用现有生产字体与纯 CSS 几何装饰；不新增图片与依赖。

### Don't

- Don't 用金色写正文段落；Don't 让金色压在米白或金色上。
- Don't 用彩虹渐变、廉价金色贴图、发光模糊或霓虹光晕冒充 deco——只用实线、实心菱形与平涂。
- Don't 抄新粗野的硬偏移阴影 / 酸性高亮，也不要落回复古纸张（那是 `editorial` / `fairy-kei` 的领域）。
- Don't 做无限循环动画、滚动劫持、光标替换、字样逐字打印或设计专属 JS。
- Don't 用颜色或形状单独传达状态；链接一律带文字标签。
- Don't 在 `Preview.astro` 里 import `style.css`、写 `:root`、声明 `<Font>`、放可聚焦元素。
