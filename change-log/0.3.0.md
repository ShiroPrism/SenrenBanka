# 0.3.0（2026-10-10）图标与品牌标志（试点）

为四套设计补充有实际语义的图标与视觉元素（链接标识、外链提示），按设计语言分发而非统一风格（决策见 `docs/adr/0002-icon-and-brand-mark-strategy.md`）。

## 新增

- **唯一图标库 `@lucide/astro`**（ISC）：构建期内联 SVG、零客户端 JS；首个图标类依赖入库。
- **品牌资产**：`src/assets/brand/github.svg`（simple-icons / CC0-1.0，含 provenance 注释；商标核对结论见 `docs/verification/shared.md`）。
- **editorial**：Elsewhere 品牌 mark（GitHub，灰墨、0.85em、静态）+ Selected Works 外链箭头（`ArrowUpRight`、1.5 描边、灰墨）。
- **terminal**：外链去向字符标记 `→`（链接行 `label → url`、项目行 `title → url`；Dim 档、`aria-hidden`）——零 SVG。
- **oxide**：CHANNELS 链接品牌 mark（filled、替换原 `▸`；未映射 slug 保持 `▸`）——不引入 lucide。
- **fast**：按钮前置图标（GitHub mark / Mail）+ 项目卡外链箭头；`.fs-btn` 改 `inline-flex` + 0.5rem gap。
- **接线**：`links[].icon` 可选 slug，各设计私有映射，未识别 / 缺省纯文本回退；所有标记 `aria-hidden`。
- **文档**：`CONTEXT.md`（术语 brand mark / functional icon / icon fallback）、`docs/adr/0002-icon-and-brand-mark-strategy.md`、`AGENTS.md` 新增「图标与品牌标志」约定与评审清单项、editorial / terminal `DESIGN.md` 增补对应章节。

## 修复（验证期暴露的真实缺陷）

- **Tailwind Preflight 的 `svg { display: block }` 导致行内图标折行**：editorial 品牌 mark / 外链箭头、oxide mark、fast 卡片箭头全部掉到文字下一行（rect 实测：图标 x 不与文本末端相接、y 越到下一行；fast 按钮因 flex 语境未受影响）。已为行内图标显式 `display: inline-block`，复测全部与文字同行且垂直居中；该坑记入 `AGENTS.md`「已知坑」。
