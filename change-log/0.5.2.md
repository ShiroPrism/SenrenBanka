# 0.5.2（2026-10-11）AGENTS.md 通用化重构：规则与专名事实分离，新增素材 / 光标与无障碍 / 响应式规则

## 变更

- **AGENTS.md 只承载通用规则**（项目所有者发起）：移除全部单一设计名称与对具体 `DESIGN.md` 的引用（4 处：滚动进度机制、持续动效清单、规范同步策略、图标适配记录指针）；文件头明确分工——各设计的具体采用情况 / 适配记录 / 偏差归口 `docs/verification/`、`docs/designs/*/ADAPTATION.md`、`CONTEXT.md` 与 `change-log/`，规则文件不再点名。
- **动效定位升级为「设计语言维度」**（沿 `docs/adr/0003` 方向）：总则「目标不是给所有元素增加动画，而是让每套设计拥有更丰富、更有辨识度的动态表现，同时保持各自的设计语言」；「每套设计必须满足」新增第 7 条——`DESIGN.md` 须定义动效语言（Motion 章节；可极简，静止须论证）；共享显现改为「采用即接入 `<Reveal />`，不用须说明替代触发与可见性契约的满足路径」；滚动进度的压缩器合并坑改为准确表述（`var()` 阻断合并）。
- **新增「Visual Assets & Cursor Rules」**：素材必要性核实（先读 `DESIGN.md`）、优先既有表现手段、远程素材许可 / 再分发核实（衔接 `SPEC §4`）、`assets/` 入库 + provenance、替代文本与构建期优化（`astro:assets`）、头像数据层统一解析、标准 CSS 光标优先、自定义光标回退 / 桌面门控 / 禁 JS 跟随特效、验证检查项。
- **新增「无障碍与响应式（Accessibility & Responsive）」**：分区可访问名、装饰 `aria-hidden` 不得进入可访问名、纯图标控件命名、对比度硬底线 4.5:1（自设更严档以更严者为准）、触控命中 ≥ 44px（`pointer: coarse`）、hover 门控、375px 零溢出、DOM 顺序与视觉层级一致、键盘可达。
- **「新增设计评审清单」扩充**：新增动效语言 / 素材合规 / 无障碍与响应式三行；原「移动端 375px」行并入无障碍行。（该清单随后于 2026-10-11 文档治理中不再由 `AGENTS.md` 维护——通过标准由 `design-page-verify` skill 承担，见 `docs/README.md`。）
- **`design-page-verify` skill**：2 处专名（检测器有效性反证示例、滚动进度检查项）改为通用表述（引用 `docs/verification/` 当前记录）。
- **术语（`CONTEXT.md`）**：新增 `Motion language（动效语言）` 与 `Visual asset（视觉素材）`。
- **版本**：`package.json` 0.5.1 → 0.5.2；验证状态与记录归属见 `docs/verification/`。
