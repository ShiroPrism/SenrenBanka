# 0.12.0 — 八方向拟物主题落地：字体资产入库 + receipt 与余下 7 套设计

2026-10-18（补记于 2026-10-19；提交 `9ebb433`）

## 背景

八方向拟物主题进入实施：先把在线候选字体以可复现方式接入生产（构建期零网络），再按设计隐喻逐套落地页面。`receipt` 为样板，余下 7 套（`archive` / `radio` / `fax` / `pager` / `tape` / `poster` / `lexicon`）同批交付。

## 字体与管线

- 18 款新字体「npm 取件 → `src/assets/fonts` 入库（许可随附）→ `fontProviders.local()`」：构建期零网络、全平台可复现；既有 6 套 npm provider 未动。
- CJK / 磨损字体子集：朱雀仿宋 8.6MB → 246KB、方舟像素 541KB → 39KB、TT2020 StyleD 827KB → 304KB。
- 工具（`.local-fonts/`，不入库）：`vendor-fonts.sh`、`make-web-subsets.py`；来源 / 许可 / 子集说明见 `src/assets/fonts/README.md`。

## 设计（8 套）

- `receipt`（样板）：热敏小票机，三联（≥1024px 三语并排 + 窗口横向滚动）/ 单联（<1024px）。
- `archive` 卡片目录 / `radio` 短波面板 / `fax` 传真传输纸 / `pager` 寻呼机 LCD / `tape` 磁带 J 卡 / `poster` 丝网海报 / `lexicon` 三语辞典。
- 每套五件套 + 三语 `messages`；`descriptions.ts` 补 8 条本地化说明（含 `receipt`）。
