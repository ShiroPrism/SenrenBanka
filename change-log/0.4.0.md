# 0.4.0（2026-10-10）四套设计差异化动效增强

为四套设计建立互不相同的"动效声音"，同时保持各自设计语言与克制（决策见 `docs/adr/0003-differentiated-motion-enhancement.md`；基础触发机制沿用 `docs/adr/0001`，其决定 1 的范围已修订）。

## 新增

- **Editorial —— 印刷**：首屏墨色渗入（眉标 → 姓名 → 定位/简介，90ms 错落，无位移）+ hero 发丝线从左绘出（520ms，backwards 起笔、默认即完整）；滚动显现：栏目头两端就位（标题自左 / 副标自右各 10px，副标慢 80ms）、作品行渗入 + 行线绘制（420ms）、Elsewhere 链接 70ms 错落、页脚整体渗入。规范先行：`DESIGN.md` Motion 章节重写 + Key Characteristics 增补。
- **Terminal —— 字符网格离散步进**：命令逐字打出（16ms/字）+ 输出落屏级联（50ms 节奏、上限 6 项）——Astro 构建期切分字符、内联 `--d` 时刻、CSS `steps(1, end)` 消费，零运行时 JS；chrome 首个圆点 2.6s 呼吸灯；光标闪烁保留。规范先行：`DESIGN.md` 新增 Motion 章节、Don't 条款修订（打字级联仅限命令与装饰行）。
- **Oxide —— 仪表**：顶部 2px 滚动进度线（CSS Scroll-Driven Animations，`@supports` 门控，不支持 / 减动态时整条隐藏）；ASCII 波形缓慢流动（32s linear、4 份首尾相接无缝循环）；链接 / 切换器 150ms ease 颜色过渡（vendor「plain ease for hover and color」）；页脚纳入显现目标。
- **FAST —— 层次与触感**：项目卡片 / 经历行滚动显现 + 错落（60 / 50ms，复用既有 `--fast-duration-normal` / `--fast-curve-easy-ease`，无新增 token）；卡片 hover（面层 + 描边 + `translate: 0 -2px` 浮起，仅真悬停设备）；按钮 `:active` `scale(0.97)` 按压反馈；页脚链接 hover 下划线。
- **文档**：`docs/adr/0003`、ADR 0001 修订节、`CONTEXT.md` 四个新术语（typing cascade / print cascade / rule draw / scroll progress）、`AGENTS.md` 动效约定重写、`design-page-verify` skill 同步（四套均含动效 + 新增滚动进度断言）。
- **厂商快照**（oxide / fast `DESIGN.md`）**未修改**；相对快照的实现取舍（波形流动、进度线）记录于 ADR 0003 与 SPEC §18。

## 实现要点 / 踩坑

- **压缩器会把 `animation-timeline` 合并进 `animation` 简写**（产物实测 `animation:linear both ox-progress scroll(root)`），当前 Chromium 不接受该简写（`CSS.supports` = false）→ 整条声明失效（实测 `animation-name` 回退 `none`、进度线死掉）。修复：timeline 值经 `var()` 传入阻断合并，保持"简写在先、timeline 在后"的语义；修复后实测 top `scaleX(0)` → 中位 `0.5004` → 底 `1`。
- 终端打字是逐字符 opacity 离散步进（非宽度动画）→ 无布局跳动、无字符位移；正文数据永远直接出现。
- 终端的键入 / 落屏隐藏态带 `:not([data-reveal-in])` 兜底：过渡失效时内容也不会被静态隐藏。
