# 0.18.0 — 外部字体目录与核心 CJK 分片

2026-10-30

## 成果

- 20 个项目自有字体族迁移到独立 `SenrenBanka-fonts` catalog v1.0.0；主项目以 lock / snapshot / generated registration 固定目录、家族包、文件清单与 SHA-256。
- Zhuque Fangsong、LXGW WenKai GB、Ark Pixel 12px 从站内用字子集升级为源字体完整 cmap 的 `unicode-range` 分片；新增资料文字不再要求按仓库文案重裁。
- 新增显式离线链路：`fonts:prepare` 校验并原子安装到 `.cache/fonts/`，`fonts:check` 完全离线复核，`fonts:audit` 扫描最终 HTML 的核心 CJK 覆盖。
- 6 个 Fontsource npm family 与 20 个 local family 的 Astro 变量只暴露主 face；完整回退链回到各设计 CSS，避免拉丁变量内的系统中文字体抢先命中。
- 新增 `fonts:typography` 静态门禁，检查全部 styled 设计与预览的显式 fallback、核心 CJK 顺序、14 套 core-CJK 设计的每个字体栈，以及 npm / local registration 的 primary-only / 离线配置。
- 新增 ADR 0012；ADR 0008 保留本地字体工作台隔离决定并标注生产分发层修订。同步 rules、SPEC、README、字体选型指南与自产设计字体记录。

## 修复

- 清除现行自产设计文档中的旧站内子集大小、覆盖承诺和资源路径；厂商只读规范不改写。
- 修正 poster、radio、receipt、pager、fax、sticker-diary 等核心 CJK 字体栈缺少显式系统中文字体尾链的问题；复核补齐 cute-alism micro 与 lexicon running/period 绕过核心字体的局部栈。
- 构建前补齐字体目录准备，GitHub Pages / Cloudflare Pages / Vercel 均使用显式 `fonts:prepare`。

## 验证结论

- `npm ci`、`npm test`（40/40）、`fonts:update` 连续两次幂等、`fonts:prepare --offline`（20/20 复用）、`fonts:check`、`npm run build` 与无效代理离线构建通过。
- 构建产物 105 页；`astro check` 0 错误 / 0 警告 / 1 条既有 hint；HTML-only 20/20 测试与 3 个产物页通过；CJK 审计输出 32 条可定位的源 cmap 缺字警告。
- 23 套 styled 设计的字体回退静态矩阵通过；产物审计 105 HTML / 24 CSS / 611 WOFF2，25 个实际注册变量、228 处声明均为主 face，非 WOFF2、第三方字体 URL 与旧字体路径均为 0。
- 全量浏览器路由矩阵 105/105 加载、0 第三方资源、0 失败响应、0 console 错误；CDP 平台字体证据覆盖全部 **14 套核心 CJK 设计**、npm provider 与切换页，普通排版均命中预期字体，非源 cmap 缺字的系统 CJK 回退为 0。
- 375px / reduced-motion / no-JS 三个代表页通过；证据、截图与剩余边界见 `docs/verification/shared.md`。
