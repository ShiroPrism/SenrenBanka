# 0.1.0（2026-10-10）初版

AI 驱动的多设计个人主页生成器——「一份个人资料，多套由 DESIGN.md 规范生成的独立设计页」的完整工作流验证版（SPEC 第一阶段全部范围）。

## 新增

- **框架**（Astro 7 + TypeScript + Tailwind CSS 4）
  - 目录即注册的设计注册表（`src/designs/registry.ts`），构建期强校验（缺四件套 / 缺 provenance 即报错）
  - 统一数据接口 `loadDesignView()`：profile 只维护一份（YAML + Zod strict 校验），所有设计共享
  - `injectRoute` 动态设计路由；每设计独立 CSS 入口（`source(none) + @source`，构建期隔离已验证）
  - 字体构建期自托管（astro:fonts + @fontsource npm provider，运行时零第三方请求）
  - 共享 `HeadMeta`：title / canonical / robots（索引策略）集中管理
- **运行时行为**
  - `fixed` / `random` 两种模式；`manualSwitch` 控制切换入口与 `/designs/` 切换页（关闭时不构建）
  - 浏览器缓存窗口 `cacheHours`（默认 24h）：窗口内保持一致、过期重随机、避免连续两次同一设计
  - 根路径 = 零外部请求路由页（内联脚本 + `<noscript>` meta refresh 降级；noindex）
  - `enabled: false` 的设计仍可直达分享，但不参与随机池与切换页
  - localStorage 键按站点命名空间化（兼容 GitHub Pages 同域多项目）
- **四套设计**（视觉差异矩阵：编辑杂志 / 琥珀终端 / 深色工业 / 明暗双主题）
  - `editorial`（自产规范）：Fraunces + 双声部排版 + 焦赭单一强调 + 杂志编辑网格
  - `terminal`（自产规范）：琥珀 CRT 终端、命令/输出信息组织、扫描线背景层
  - `oxide`（官方 OxIG 规范快照，MPL-2.0）：ASCII 网格 + "Visible grids" 工业风
  - `fast`（官方 Microsoft FAST 规范快照，MIT）：语义 token + `light-dark()` 双主题卡片
- **质量与工具链**
  - `design-page-verify` skill：设计页完整验证流程（构建 / 产物隔离 / 检测器 / 桌面实测 / 375px 触控仿真 / a11y / 对比度 / 记录收口）
  - `AGENTS.md` 实现约定 + 新增设计评审清单；`SPEC.md` 契约文档（含实施记录）
  - impeccable 集成：设计规范文档化（`document`）、dual-agent 评审（`critique` / `audit`）、检测器（四套设计终态 0 发现，1 条已记录例外）
- **部署**
  - GitHub Actions workflow：fork 后零配置（自动注入 `SITE_URL` / `BASE_PATH`）
  - Cloudflare Pages / Vercel 部署说明（README）

## 修复（开发与验证期暴露的真实缺陷）

- Astro `BASE_URL` 无尾斜杠导致 base 前缀拼接错误
- `fixed` 模式错误读取遗留存储（违反既定状态表）
- oxide 页脚 nowrap ASCII 波形导致移动端横向溢出
- editorial 桌面首屏 `align-items: end` 造成"简介先于定位语"的分组倒置
- fast 触控命中区缺失（实测 35.6 / 19.3 / 21.6px → 修复后 46.8 / 44.2 / 46.5px）
- 字体回退链：Astro 注入的无衬线优化回退排在预期衬线/等宽回退之前（配置 `fallbacks` 修正）
- editorial 强调色越权与文档计数口径冲突（One Accent Rule 收权并厘清"按栏目计数 + 交互态豁免"）
- terminal 扫描线绘制在文字层之上（迁入屏幕背景层，dim 最坏扫描行 ≥5:1）

## 已知限制

- 真机（iOS / Android）、Safari 引擎、横屏、200% 缩放未实测；触控验证基于 Chromium 仿真
- oxide 保留 1 条 `codex-grid-background` 检测器 advisory——源自官方规范 "Visible grids" 原则，有意保留
- 字体无法按子集过滤（npm provider 不填 subset 元数据）；editorial 已移除 preload 以避免预载未使用子集
- 访客统计、账号系统、后端、在线编辑器、设计市场等留待后续版本（见 SPEC 二期清单）
