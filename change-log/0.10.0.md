# 0.10.0 — 全站共享操作菜单：移动端悬浮球、页面上下文与触屏可达（ADR 0007）

2026-10-13

## 背景

v0.9.0 把语言切换并入右键菜单的语言二级菜单后，语言切换成为菜单的**唯一入口**，触屏不可达不再是"少一个便利功能"而是移动端无法换语言。ADR 0004 曾明文否决移动端替代入口，SPEC §7.5 为此预留了退路（"另加页面内入口而非改回逐设计排版"）。本版执行该退路，并顺带修复 v0.5.0 起就存在的切换页接入缺口。

## 成果

- **全站共享操作菜单（Action menu）**：菜单数据、文案、动作处理与状态语义在所有输入环境完全共享，只有容器形态分叉——桌面为贴近光标的浮层菜单，移动为底部动作面板。`CONTEXT.md` 新增 `Action menu` / `Menu trigger` / `Launcher` / `Page context` 四条术语，`Context menu` 降级为桌面形态之一。
- **移动端入口**：右下角悬浮球（48×48px，让开安全区，`aria-*` 齐备）点击打开底部动作面板。不依赖长按、不拦截原生长按与文本选择；语言项在面板内**平铺**（触屏没有 hover 二级菜单的心智模型）。
- **页面上下文判别联合** `design` / `switcher` / `not-found` 取代可空的 `currentId`。菜单据此决定身份条、随机排除、切换页项显隐与语言项目标；**随机主题在所有页面可用**，切换页与 404 走全池（绝不排除一个不存在的"当前主题"）。
- **接入面补齐**：8 套主题 × 3 语言、`/{locale}/designs/`、404 全部接入（切换页是 v0.5.0 起的缺口）。四类"立即跳转"页（`/`、`/{locale}/`、旧路径跳转）不接——它们停留不足一帧。
- **混合输入设备按真实输入能力处理**：媒体查询初判 + `pointerdown` 的 `pointerType` 校正，结果存会话级 `sessionStorage`（与主题偏好的 `localStorage` 键空间隔离）。
- **渐进增强**：SSR 同时输出两份 DOM，按环境用 `hidden` 摘除（同时移出无障碍树）；切换页与 404 的可见 `LanguageSwitcher` 包进 `<noscript>`，运行时只有菜单一个可见入口。
- **`contextMenu.enabled` 字段删除**——它恒为 `true` 且与 `designActionsEnabled` 职责重复；一并修掉 `AGENTS.md` 中两条互相矛盾且代码已不遵循的编号条款。

## 修复的缺陷

实测暴露并已修正：

1. **桌面态菜单常驻可见**：`applyMode()` 误写 `root.hidden = touchMode`，导致浮层菜单初始不隐藏。
2. **`→` 无法进入子菜单 + 子菜单内 `↑↓` 循环错层**：层级判据原为 `subOpen`（子菜单是否展开），但 `↑↓` 移到触发项会自动展开而焦点仍留在此，此时 `→` 被 `if (subOpen) return` 拦掉。改为按「焦点实际所在处」判定。
3. **`data-cm-sub` 死代码清理**：该属性设置与移除都有、但无任何 CSS / JS 消费者。
4. **`hidden` 被作者样式压过 → 移动端面板恒开、悬浮球不可见**（项目所有者实测发现）：面板与悬浮球都声明了 `display: flex`，作者样式表优先级高于 UA 的 `[hidden] { display: none }`，两者无视 `hidden` 恒常可见。修法：加 `[hidden] { display: none }` 兜底规则。
5. **面板显隐逻辑写反**：原写 `sheet.hidden = !inTouchMode()`，移动端下恒为 `false`（等于永远打开）。改为形态切换时全部先收起、面板显隐只由开合状态驱动。
6. **入场动画可能全程不推进**：面板动画起点原为 `translateY(100%)`，动画未播完时面板停在视口外，用户点悬浮球像没反应。改为起点 `translateY(14%)`（退化时仍有 86% 可点）+ 不用固化起始帧的 fill-mode + `animationend` 后回到自然终态。
7. **点悬浮球图标打不开面板**：判定写的是 `target === launcher`，点在按钮内部的 `<svg>` 上时 `event.target` 是图标而非按钮，判定失败 → 面板刚打开就被同一笔点击的冒泡关掉。改为 `contains()` + 图标 `pointer-events: none`。
8. **面板无可见关闭控件（重做为 action sheet）**：原先唯一出口是点遮罩，触屏上等于要求用户去"瞄准"一块没有可点击暗示的暗色区域。重做为 `bar` / `body` / `foot` 三段结构，面板内新增三条显式关闭路径——头部 ✕ 按钮（44px）、底部取消条（48px）、抓手条下拉手势（跟手 + 阈值 1/4 + 短滑回弹）；遮罩降为兜底。同时补 200ms 退场动画、`backdrop-filter` 分层、三语言分组标题（页面 / 设计 / 语言）。
9. **悬浮球改为反相配色**：中性白底会"融"进浅色主题内容，深色药丸在 8 套主题上都是明确的浮层；`:active` 缩放提供按压反馈，面板打开时淡出。
10. **移动端裁掉桌面不适用的动作（项目所有者两轮指出，调研确认）**：`ContextMenu.astro` 拆成 `desktopActions`（5 项）/ `sheetActions`（**2 项**）两个构建期清单。移动端移除三项：
    - **「重新加载」**（第二轮追加）——移动浏览器页首内置下拉刷新。上一轮刚论证下拉刷新比下拉手势重要、把面板的 `touch-action: none` 移除以把通道还给浏览器，转头又留了个「重新加载」，两处自相矛盾。
    - **「回到页面顶部」**——NNGroup：短于 4 屏属 overkill；iOS 另有"点屏幕顶端回顶"原生手势。
    - **「打印 / 保存为 PDF」**——iOS Safari 16+ 完全忽略 `window.print()`，Android Chrome 默认隐藏打印入口，两端都是"点了没反应"。
    - 桌面端三项全部保留（桌面肌肉记忆是 F5 / Ctrl+R，且 `window.print()` 能真正弹窗）。
    - 由此确立判断标准：**不是"桌面菜单里有什么"，而是"整个平台已经原生提供了什么"**。据此复查保留的两项——`copy`（原生长按地址栏拷贝要 2~3 步且把用户带离页面）、`share`（`navigator.share()` 唤起的就是系统原生分享表单本身）——都是缩短路径而非重复，保留成立。
    - 面板三轮裁剪后 600px → **518px**，375×812 下从"需要滚动"变成"一屏放得下且底部不留空"。
11. **移除下拉关闭手势（项目所有者指出）**：该手势需 `touch-action: none` 抢占触屏手势，代价是**整站页面顶部的下拉刷新一并失效**。为"少点一次 ✕"牺牲刷新能力不成立。抓手降级为纯装饰短横，关闭路径回到面板内的 ✕ + 取消条两条显式控件。
12. **动作裁剪后重排版面**：项高 52→48px、组间距收紧；组标题选择器 `:first-child` → `:first-of-type`（身份条 `cm-head` 存在时 `:first-child` 会误命中导致首个分组丢失上边距）。组标题选择器 `:first-child` → `:first-of-type`（身份条存在时 `:first-child` 会误命中导致首个分组丢失上边距）。

顺带修正 `SPEC.md` 中三处过期数据（「四套设计」「七页」「触屏设备零菜单 JS 请求」）。

## 验证结论

`npm run build` **41 页**绿（`manualSwitch:false` 时 37 页），`npx tsc --noEmit` 0 错误。

本机 Chromium 实测（`astro preview` + Playwright），完整矩阵见 `docs/verification/action-menu.md`：

- 桌面右键 / `Shift+F10` 打开、视口收敛；链接 / 选中文字 / 非交互区三种情形的原生菜单保留行为逐一断言。
- 键盘：主菜单 `↓` 循环不飞出；子菜单内 `↓` 在 3 个语言项间循环、`Home`/`End`/`←`/`→` 均符合契约；点击亦可展开（不依赖 hover）。
- 375×812：悬浮球 48×48、面板高 626px 且 `bottom === innerHeight`、面板内 10 项均 51px、无横向溢出、背景滚动被锁、遮罩与 `Esc` 两条关闭路径均解锁并可重开。
- 三种页面上下文的语言与主题跳转正交性全部成立；`manualSwitch:false` 下主题组消失而菜单与语言分组保留；剪贴板双失败降级为 error 档 Toast。
- CSS 隔离与 `modulepreload` 计数 0 均保持。

**未覆盖项**（已在 `action-menu.md` 如实声明）：`/demo` base 全链路（本机存在环境变量污染，未在干净环境复测）、真机 iOS 的滚动穿透、大屏一体机实机、真实分享面板、8 套设计的移动端观感仅逐页核对了标记（editorial 有截图）、打印实际输出。
