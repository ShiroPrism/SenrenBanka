# 0.11.0 — 字体系统文档归档：本地字体工作台与在线候选调研（ADR 0008）

2026-10-18（补记于 2026-10-19；提交 `7368595`）

## 背景

新增拟物主题需要成体系的字体选型依据：本机个人字体库（目录联接入口，543 文件 / 722 face）此前既无识别工具、也无样张预览与许可闸门规则。同时按需求补充在线开源来源调研，明确再分发的红线。

## 成果

- `docs/fonts/selection-guide.md`（新增）：五步选型流程（设计隐喻 → 候选发现 → 样张目检 → 许可闸门 → 生产接线与六项记录）、六方向维度表、工具契约与回退策略；§2.5 在线来源补充通道（先核验许可含 RFN 再下载、CJK 子集纪律、状态口径）。
- `docs/adr/0008-local-font-library-isolation.md`（新增）：本地层（发现 / 预览，不入库）与生产层（许可闸门 + `fonts` 注册）严格隔离，并记录三个被否决方案。
- `AGENTS.md`：新增「字体（Typography & Fonts）」节（选型顺序 / 本地工作台 / 在线候选 / 许可闸门 / 记录位置 / 生产接线）；「每套设计必须满足」第 5 条加交叉引用。
- `CONTEXT.md`：新增 Fonts 四术语（本地字体库 / 字体清单 / 字体样张 / 许可闸门）。
- `docs/README.md`：索引新增字体指南与字体链路；`SPEC.md` §8.5 指针与 §11 目录树同步。
- 工具、扫描清单、候选记录与在线调研结果均只存 `.local-fonts/`（gitignore 已覆盖），不入库、不进构建。

## 验证结论

- 本地库全量扫描（543 文件 → 722 face，完整 cmap 口径）；样张服务器字节级验证（sha256 一致、TTC 拆包经 fontace 复验、Range 206）。
- CDP 交互冒烟 7/7 + 无头 Chrome 截图；在线候选 31 face 同扫描器实测 + 第二实例浏览器样张。
- `npm run check` 0/0/0；`npm run build` 41 页通过；`dist` 无字体库文件、无本机路径泄漏、无第三方字体域名。
