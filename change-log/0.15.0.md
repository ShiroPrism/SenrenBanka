# 0.15.0 — 旧设计字体审计与系统默认字体替换

2026-10-19

## 背景

字体选型指南建立于 2026-10-17（`7368595`），此前的九套设计没有统一的字体审计记录。`oxide` 还存在真实接线断裂：`style.css` 声明 `SuisseIntl` / `GT America Mono`，但两族从未注册、页面没有 `<Font>`，浏览器只能静默回退系统字体。本版对 `archive` / `editorial` / `fast` / `terminal` / `oxide` / `material3` / `kern` / `govuk` / `frost` 做一次可追溯审计，只修复有证据的缺陷，不为“更艺术”批量换字。

## 成果

- **Oxide 接线修复**：复用既有 Geist Variable / Geist Mono Variable，`Page.astro` 加入两个 `<Font>`，`style.css` 以 `@theme inline` 建立 `--font-oxide` / `--font-oxide-mono` 别名；不再保留无文件的 SuisseIntl / GT America Mono 字符串。切换页预览同步导出两族，仍按族去重。
- **Terminal 保留 JetBrains Mono**：浏览器实测 15px 正文可读、latin 主文件约 40,404 B；VT323 / Share Tech Mono 缺现有波形、框线与状态符号，且不适合正文。正式页与预览补齐 `Segoe UI Symbol` / `Apple Symbols` → 系统中日文字体 → `monospace` 的显式回退。
- **Editorial / Kern / Frost 保留现字体**：Fraunces + Georgia + 系统标签、Geist + Geist Mono、Inter 均通过样张与覆盖复核；新增字体没有明确收益，只会扩大切换页字体并集。六项记录补入各自 `DESIGN.md`。
- **Fast / GOV.UK 保持系统字体**：Segoe UI 与 Arial 分别是厂商 / 上游明确口径；GDS Transport 不可再分发，不为“更有性格”替换。Material 3 保留 Roboto Flex 同源实现。四套厂商来源的六项记录写入 `ADAPTATION.md`，只读 `DESIGN.md` 未改。
- **字体回退增强**：`astro.config.mjs` 为 Fraunces / JetBrains Mono / Roboto Flex / Geist / Geist Mono / Inter 补入系统中文、日文与符号字体；不新增字体包、不引入运行时字体 CDN、不依赖服务器。
- **字符覆盖证据**：Geist Mono symbols2 实测覆盖 `▁▂▃▄▅▆▇█└─`；Geist Mono / JetBrains Mono 均不覆盖 `● ■ → ▸ ↗ ▣ □ ○ ▲ ▶ ▼ ◀`，由系统符号字体承接。Oxide 页脚 `▸`、品牌 `●` 与预览 `↗` 均保留原设计字符。
- **预览与成本**：预览继续只导出 `fonts` 数组、不各自声明 `<Font>`、不 import 正式页 `style.css`；0 preload，CJK 子集按 `unicode-range` 惰性下载。Oxide 改用已有字体族，不增加切换页字体族种类；切换页在实际渲染后由 0.14.0 的 22 个唯一 WOFF2 增至 **25** 个（**净增 3 个文件、58,340 B**），增量为 Geist latin、Geist Mono latin 与 Geist Mono `symbols2`（波形块字符）按需请求。该数字是净增量，不是整页字体总成本；25 个文件合计 **1,199,652 B**（约 **1.14 MiB**），扩展评估需同时监控字体总量。

## 验证结论

`npm run check` 0 错误 / 0 警告 / 1 条既有提示（`lexicon/Page.astro` 未用参数，与本版无关）；`npm run build` **73 页**绿。

| 断言 | 结果 |
|---|---|
| Oxide 接线 | `document.fonts` 非空；Geist / Geist Mono 均命中；无 SuisseIntl / GT America Mono 残留 |
| Terminal | JetBrains Mono 命中；符号与中日文回退链显式；0 preload |
| 九套记录 | 自产 / 复刻五套写入 `DESIGN.md`；厂商四套写入 `ADAPTATION.md`；厂商 `DESIGN.md` diff 为 0 |
| 预览隔离 | 16/16 预览不 import 正式页 `style.css`、不声明 `<Font>`、无 `:root`、无可聚焦元素 |
| 设计页隔离 | 16 套 × 3 语言：每页恰 1 条自身 CSS、0 个预览选择器 |
| 切换页字体 | 82 个 `@font-face` / 38 个生成族名（与 0.14.0 相同）；实际请求 25 个唯一 WOFF2（基线 22，净增 3 个、58,340 B；总计 1,199,652 B，约 1.14 MiB）；0 preload；无第三方字体域名 |
| 降级 | 断网 / 字体失败时正文可读；reduced-motion、无 JS、无 IO 不隐藏内容 |
| 响应式 | 桌面三列、移动单列；375px 无横向溢出 |
| 检测器 | 既有例外不变：oxide 1 条 `codex-grid-background`、frost 2 条 `bounce-easing`、govuk 2 条 `overused-font` |
