# 0.8.0（2026-10-11）批次 3：新增 GOV.UK Design System（汇编）与 Frost（HIG 复刻）

## 成果

- **新增第 7 套设计 `govuk`**（GOV.UK Design System，`official-docs-derived` 汇编）：按当日上游（**2025 品牌刷新后**）现状整合官方指南（OGL v3）与 govuk-frontend 源码数值（MIT）——功能色体系（brand 蓝页眉 / 功能 link `#1A65A6` / border `#CECECE` / 绿按钮 `#0F7A52` / 蓝 tint 标签）、11 组网络调色板、响应式型阶（53→80 / 48 / 36 / 27 / 24 / 19 / 16）、1020/960 容器 + 30px gutter、间距标尺、边框标尺（5/10/4/2px）、三种黄黑焦点、按钮 / 标签 / inset text / summary list / 页眉 / 页脚数值；OGL v3 + MIT 全文与署名句式见 `SOURCE-LICENSE.txt`；Arial 回退、组件手写复刻、静态动效取舍与纹章 / 标识边界见 `docs/designs/govuk/ADAPTATION.md`。
- **页面实现**：蓝幅页眉 + 48px 标题 + 蓝色标签（`<strong>` 句首大小写）+ summary list 经历 + inset text 联系 + 绿按钮（2px 硬阴影 + 按压位移）+ skip link（黄黑焦点）；**静态设计**（无入场 / 显现动画，经论证；本项目首个不接入共享 Reveal 的设计）；无自托管字体（上游回退 Arial 系统栈）。
- **新增第 8 套设计 `frost`**（复刻席第二套，`third-party-analysis`）：对 Apple HIG「材料与层次」语言的**非官方致敬复刻**——自撰规范 + 极光底上的**两层材料**（导航功能玻璃 `0.60/0.55` / 卡片标准材料 `0.78/0.72`，`blur(20px) saturate(180%)`）+ iOS 系统色（单蓝 + 三档灰）+ 17px 型阶 + 胶囊控件 + 弹簧动效 + 分级离退（`prefers-reduced-transparency` / `@supports` 双回退）；命名同批提案定稿（`frost` / Frost）；不复用任何上游文本 / 素材 / 品牌资产。
- **复刻席机制连续走通**：命名提案 → 自撰规范 → 实现 → 全流程；HIG `materials` 页的「两种材料」教义被映射为双层材料规则（功能层玻璃 vs 内容层标准材料），作为复刻的核心结构。

## 修复 / 加固

- **frost Filled 胶囊对比修正**：白字在深色档系统蓝 `#0A84FF` 上仅 **3.65:1**（AA 不过）→ 新增 `accent-solid #0071E3`（深浅同值）作为填充底；浅色强调蓝亦取 `#0071E3`（`#007AFF` 不达 4.5）——规范与实现同步。
- **玻璃路径的测量口径确定**：本机 headless Chromium 默认 `prefers-reduced-transparency: reduce`（回退按设计正确生效）→ 玻璃观感以 CDP 显式仿真 `no-preference` 实测与截图归档；三态（默认 / no-preference / reduce）均实测。
- **govuk 触控命中补齐**：按钮 coarse 下 padding 12/11（命中 46px，保持 1px 阴影补偿）、行内链接 0.75rem（命中 49px）。
- **检测器闭环**：frost 首轮 9 条 `design-system-color`（极光色）→ 作为设计系统值补入 `DESIGN.md`（`colors.aurora-*`）后清零；govuk `overused-font`（Arial，上游回退口径）与 frost `bounce-easing` ×2（弹簧语言）**均记录为例外**（各 `ADAPTATION.md`「检测器例外」节）。

## 未测 / 限制

- 真机（iOS / Android）与 Safari / Firefox 引擎未实测（Chromium 仿真）；同两主题验证文档「未测 / 限制」节。
