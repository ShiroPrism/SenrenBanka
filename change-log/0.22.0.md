# 0.22.0 — 入口语言协商与零窗口随机

2026-11-22

## 成果

- 根入口 `/` 改为按「手动语言偏好 → `navigator.languages` → 默认 Locale」协商 Locale，再进入该 Locale 的随机 / 固定设计；`/<locale>/...` 仍路径语言优先。
- 新增独立语言偏好键 `senrenbanka.locale.v1:<baseKey>`；只在共享操作菜单语言链接被显式激活（点击 / Ctrl-Cmd 点击 / 中键）时写入，直接访问 Locale 页面不覆盖偏好。`html-only` 因零脚本契约不持久化，已在文档声明。
- 当前部署改为零窗口随机（`cacheHours: 0`）：每次从入口进入都重抽并避免连续重复；`/<locale>/<design>/` 直达、刷新、书签与分享保持稳定。
- 无 JS 根入口维持 meta refresh 到默认 Locale 默认设计与设计列表，不新增语言链接；SEO robots / canonical / hreflang 策略不变。
- 更新 `SPEC.md`、`README.md`、`docs/rules/{data-and-i18n,action-menu,operations}.md`、`design-page-verify` skill、共享验证记录与 ADR 0024（Accepted）。
- 版本升到 **0.22.0**。
