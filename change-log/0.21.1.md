- 退役 `magical-girl`：删除设计目录、`script.ts`、当前验证记录与切换页描述；切换页、随机池、语言入口与旧路径入口不再包含它。

- `src/designs/descriptions.ts` 删除五语言说明；`scripts/fonts/typography.mjs` / 测试期望 **27 → 26**。
- 当前态文档收口：`README.md`、`SPEC.md`、`docs/README.md`、`docs/rules/operations.md`、`docs/verification/{shared,traditional-chinese}.md`；`design.exclude` 示例改为 `[archive]`。

- 默认设计保持 `editorial`；`design.default` / `design.exclude` 实际值不变。

## 为什么退役

`magical-girl` 的技术验证通过，但它把主分区替换成「魔法道具 / 星轨章回 / 变身年表 / 技能封印 / 蜡封信笺」，第一次访问者必须先解码主题才能找到项目、经历、技能与联系。它与 `shelf` 属于同一类问题：**主题只能改皮，不能改信息架构**。规则见 `docs/rules/design-contract.md`「信息架构与主题文案」。
