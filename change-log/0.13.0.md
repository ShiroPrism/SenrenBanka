# 0.13.0 — 切换页设计预览：自包含 `Preview.astro`（3 套原型）

2026-10-19

## 背景

切换页 `/{locale}/designs/` 此前只用「displayName + 本地化描述 + accent 色点」表示一套设计，访客点进去之前无法感知其视觉语言。静态截图会随设计演进过期、需要额外维护管线、无法随语言变化，并引入二进制资产与许可问题——因此改为**代码生成的轻量预览**。

## 成果

- **可选预览碎片**：每套设计可提供 `src/designs/<id>/Preview.astro`，自包含、纯 CSS、无交互依赖；缺失时卡片自动回退为原 accent 色点形态，注册表四件套契约不变。
- **令牌单一来源**：调色板从 `style.css` 迁入同目录 `tokens.css`，作用域为命名空间类（`:is(.ar, .ar-pv)`），正式页与预览共用同一份量值。
- **页面级字体去重**：预览导出 `fonts`（`CssVariable[]`），切换页收集后按族声明一次 `<Font>`——`@font-face` 数量随**字体族数**增长，不随预览数量线性膨胀。
- **自动发现**：切换页 entrypoint 内 eager glob `../designs/*/Preview.astro`，天然容忍缺失、无需维护 import 清单，且不把预览 CSS 聚合进其他页面。
- **三套原型**（刻意拉开覆盖面）：
  - `terminal` — 琥珀磷光屏、屏框三圆点、扫描线、`$ whoami` / `ls links/` 与块状光标（极端视觉）。
  - `archive` — 胡桃木抽屉、马尼拉索引卡、凸出类目签、印刷横线、点引导条目、`SB · 03 · 03` 索书号与「已归档」红章（原 `:root` 令牌风险）。
  - `fast` — 企业 hero、wordmark 分隔线、品牌蓝实心 + 描边按钮、三列卡片网格；系统字体，**零字体成本**。

## 修复的缺陷

**预览文件被正式页的 Tailwind 扫描**：各设计 `style.css` 的 `@source "./"` 会连带扫描同目录 `Preview.astro`，把其 `<style>` 里的属性文本（`display: flex` / `border:` / `transform:` / `flex-wrap:` / `ease-in-out`）当作候选工具类，把 `.flex` / `.border` / `.transform` / `.flex-wrap` / `.ease-in-out` 与配套 `@property` 注进**正式页** CSS（实测约 +1.3KB/页），并让「改预览」静默影响正式页样式。已加 `@source not "./Preview.astro";`（Tailwind 4 否定来源语法，4.3.3 实测支持）——修复后新增工具类归零。

## 验证结论

`npm run build` **73 页**绿；`astro check` 0 错误 / 0 警告 / 1 条既有提示（`lexicon/Page.astro` 未用参数，与本任务无关）。

| 断言 | 结果 |
|---|---|
| 切换页样式表 | **恰好 1 条**（10 149 B）；0 preflight、0 任一设计整页选择器 |
| 切换页 `:root` 设计令牌 | **0**（仅框架 `--font-*` 变量） |
| 设计页预览选择器 | **0**（16 套 × 3 语言）；每设计页仍恰 1 条自身 CSS |
| `@font-face` | **21**（4 族去重）；反证：向 `terminal` 加入 `archive` 已用的族 → 仍为 21，已还原 |
| 无障碍（CDP 无障碍树） | 预览文字**零泄漏**、`aria-hidden="true"`、0 可聚焦元素、Tab 不进预览 |
| 回退 | 移出某 `Preview.astro` 后构建仍绿、卡片回退不破版 |
| 降级 / 移动 | reduced-motion 动画全 `none`；375px 三语言 0 横向溢出；console 0 错误 |
| 对比度 | 预览内最低 5.00 / 6.75 / 5.16，均 ≥ 4.5:1 |
| 等价重构 | 三个设计页产物与改动前**逐字节一致**（归一化 CSS 文件名后 sha256 相等） |

**成本与规模**（zh-cn 切换页）：CSS 0 → **10.1KB**（单资源）；HTML 35.6KB → **46.8KB**；`@font-face` 0 → 21。线性外推 16 套 ≈ 54KB CSS，114 套 ≈ 386KB CSS / ~188KB HTML。瓶颈是 **CSS 体积 + DOM 节点数，不是请求数**；建议铺开时先加 `content-visibility: auto`，分页 / 按需加载属过早优化，未引入。
