# 0.17.0 — 六套可爱风独立设计

2026-10-29

## 成果

- 新增 `fairy-kei`：打开的复古玩具收藏盒，用中央收藏窗、悬挂链接饰品、包装说明卡、玩具抽屉、丝带卷轴、贴纸册与便签组织完整资料。
- 新增 `sticker-diary`：可翻页的手工贴纸手帐；书签、前后按钮与方向键切换跨页，无 JS 时退回完整长文档。
- 新增 `pixel-pet-rpg`：像素宠物小镇；HUD、真实地图节点、地点面板、物品栏与足迹日志组织资料，不伪造游戏统计。
- 新增 `little-forest`：从入口木牌沿 S 形小径通往小屋的童话森林绘本，用路标、树轮、野花标本与观察卡承接资料。
- 新增 `cute-alism`：粗黑描边、硬阴影、错位糖果色块贯穿全页的几何拼贴系统，与既有 Poster 的丝网印刷结构区分。
- 新增 `magical-girl`：魔法少女角色档案与舞台登场，以原创星轨、缎带、魔法阵、章回卡、封印与蜡封信组织资料。
- 六套均完整覆盖 `zh-CN` / `ja` / `en`，条件渲染全部非空可选字段；无新 Profile 字段、外部位图或第三方交互依赖。
- 新增 ADR 0011，允许设计目录私有、严格渐进增强的 JavaScript；同步设计交付契约、视觉规则与领域术语。
- 新增 `Fredoka Variable` 与站内子集化的 `LXGW WenKai GB Medium` 两族，OFL-1.1；其余角色复用既有字体。
