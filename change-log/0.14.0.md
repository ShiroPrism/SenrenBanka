# 0.14.0 — 切换页设计预览 16 套全铺 + 三列响应式栅格

2026-10-19

## 背景

0.13.0 只交付了 `archive` / `fast` / `terminal` 三套预览原型。其余 13 套设计仍以「色点 + 名称 + 描述」出现，访客在切换页无法感知它们的布局骨架、字体角色与标志性装饰。本版按项目所有者裁定，把铺开范围改为 **16 套全铺**，同时把切换页从单列长列表改为桌面最多三列、移动端单列的响应式栅格。

## 成果

- **16 套预览全铺**：新增 13 套 `Preview.astro`——`editorial` / `fax` / `frost` / `govuk` / `kern` / `lexicon` / `material3` / `oxide` / `pager` / `poster` / `radio` / `receipt` / `tape`；连同既有的 `archive` / `fast` / `terminal` 共 16 套。
- **视觉签名而非通用卡片**：每套保留自身最有辨识度的布局、字体角色、配色与装饰。例如 `fax` 的走纸孔与传输表头、`pager` 的塑料机壳与 LCD、`poster` 的巨幅窄体与套准十字、`radio` 的刻度盘与琥珀段码、`tape` 的双卷轴与手写贴标；不把 16 套统一成同一种缩略卡。
- **令牌单一来源**：13 套新增 `tokens.css`（`editorial` / `fax` / `frost` / `govuk` / `kern` / `lexicon` / `material3` / `oxide` / `pager` / `poster` / `radio` / `receipt` / `tape`），正式页与预览共用同一份量值；`pager` 原有的 `:root` 全局令牌迁入命名空间类，切换页设计根令牌归零。字体角色仍留在正式页 `@theme inline`，预览直接引用框架 `--font-*` 变量。
- **三列响应式栅格**：`.infra` 内容宽度改为 `min(74rem, calc(100% - 3rem))`；桌面 `repeat(3, minmax(0, 1fr))`，`<=60rem` 两列、`<=48rem` 单列；同一行卡片等高。无 JS、无分页、无搜索 / 筛选或按需加载。
- **隔离加固**：16/16 套正式页 `style.css` 增加 `@source not "./Preview.astro";`，避免 Tailwind 扫描预览 `<style>` 中的属性文本；预览不 import 正式页 `style.css`，不声明 `<Font>`，不含 `:root`、无可聚焦元素。
- **字体去重与成本控制**：切换页收集 16 套预览导出的 **23 个唯一字体变量**，按族去重后页面级声明一次；0 preload，CJK 子集按 `unicode-range` 惰性下载。`govuk` / `fast` / `oxide` 等系统字体设计导出 `[]`。

## 验证结论

`npm run build` **73 页**绿；`astro check` 0 错误 / 0 警告 / 1 条既有提示（`lexicon/Page.astro` 未用参数，与本版无关）。

| 断言 | 结果 |
|---|---|
| 预览覆盖 | 16/16 设计均有 `Preview.astro`；三语言切换页各渲染 16 个预览 |
| 切换页样式表 | 恰好 1 条 `SwitcherPage.*.css`，**51 963 B**；0 preflight、0 `--tw-` |
| 切换页设计令牌 | 0 个 `:root` 设计令牌 |
| 设计页隔离 | 16 套 × 3 语言 = 48 页：每页恰 1 条自身 CSS、0 个预览选择器 |
| 正式页等价 | 16 套 zh-cn 设计页与 HEAD 独立构建基线（归一化 CSS 文件名后 sha256）**全部相等** |
| 栅格 | 1536 / 1280 / 1024 = 3 列；960 / 900 = 2 列；768 / 375 = 1 列；全档 0 横向溢出 |
| 无障碍 | 预览统一 `aria-hidden`；0 个可聚焦元素；16 个卡片链接的无障碍名不含预览文字 |
| 降级 | reduced-motion 动画全停且内容可见；无 JS / 无 IO 均无预览隐藏，console 0 错误 |
| 字体 | **82** 个 `@font-face` 声明、38 个生成族名；每种语言运行时实际请求 22 个唯一 woff2，全部 HTTP 200，0 preload |
| 检测器 | 13 套零发现；既有已记录例外：`frost` 2 条 `bounce-easing`、`govuk` 2 条 `overused-font`、`oxide` 1 条 `codex-grid-background` |

**成本与规模**（zh-cn 切换页）：CSS **51 963 B**（单资源）、HTML **89 379 B**、`@font-face` **82**。按当前体量线性外推，114 套约 **370 KB CSS / 637 KB HTML**；瓶颈仍是 CSS 体积与 DOM 节点数，不是请求数。本轮不引入分页 / 按需加载 / 服务器依赖；扩展至约 100 套时优先评估分类、`content-visibility: auto` 与预览进一步精简。
