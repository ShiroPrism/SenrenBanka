# 0.20.0 — 核心字体内容子集与 10 MiB 体积门禁

2026-10-31

## 成果

- 新增核心字体 source cache：`fonts:prepare` 为 `core-cjk` family 下载并验证 catalog source archive 到 `.cache/font-sources/`；`fonts:check` 完全离线复核。fork 用户不需要本地字体、Python 或 fontTools。
- 新增 `fonts:subset`（`node scripts/fonts/cli.mjs subset [--dist dist] [--dry-run]`）：按最终 `dist` 语料用 `subset-font@2.9.0`（HarfBuzz WASM）从源字体生成每族一个 WOFF2 子集，替换页面上的核心分片 `@font-face` 为一条无 `unicode-range` 的子集规则。
- `fonts:prune` 继续处理非核心分片、字体 CSS 外置与文件删除；体积门禁从 15 MiB 收紧到 **10 MiB**。
- `fonts:audit` 对无 `unicode-range` 的核心子集规则使用 `fontkitten` 读取真实 cmap，源字体覆盖但子集缺失的 CJK 字符会使构建失败。
- 新增 ADR 0014，记录源字体完整、部署内容子集的取舍与许可依据；ADR 0013 的分片裁剪继续承担非核心字体/回退路径。
- `fontkitten@1.0.3` 成为直接 devDependency；`subset-font@2.9.0` 新增 devDependency。
