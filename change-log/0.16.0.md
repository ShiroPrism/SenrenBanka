# 0.16.0 — Homepage '99 与 HTML Only 双主题

2026-10-29

## 背景

站点已有 16 套 `styled` 设计，但缺少两类边界明确的设计：

- 一套模拟 1998–1999 年个人主页组织方式的 Web 1.0 主题；
- 一套证明同一份资料在零自定义 CSS / JavaScript 下仍完整可读、可导航的原生 HTML 主题。

`HTML Only` 与“所有设计必须有 `style.css` 且无条件接入共享菜单”的旧契约冲突。用空
CSS 文件或缺失文件伪装模式会把有意例外和配置错误混在一起，因此引入显式渲染模式。

## 成果

- `design.json` 新增 `renderMode: "styled" | "html-only"`，缺省 `styled`。既有 16 套
  manifest 不需改动。
- `html-only` 必须有 `DESIGN.md` / `design.json` / `Page.astro` / `messages.ts`，
  禁止 `style.css` / `tokens.css`；可提供完全自包含的 `Preview.astro`。
- 新增 `homepage99`：左目录 / 密集中栏 / 徽章轨的三区个人主页，系统字体、粗双线、
  88×31 徽章、明确离线的计数器，以及唯一一条 9 秒施工斜纹。
- 新增 `html-only`：只用语义 HTML、`HeadMeta` 与普通链接；三语切换、设计切换、
  base path 与 SEO 全部沿用既有路由和数据层，不接入字体、Reveal、共享菜单或样式。
- 新增 `scripts/verify-html-only.mjs`：读取最终产物，逐 `html-only` 设计 × locale
  禁止 `<style>` / `<script>` / `style=` / `on*` / 活动嵌入内容 / 未获准 `<link rel>` /
  `javascript:` URL / meta refresh；无候选、缺页或缺 dist 均 fail-closed。
- 新增 20 项 Node 内置回归测试，覆盖正例、`title` / `textarea` 文本误报，以及注释、
  属性解析、URL 编码与 `srcset` 等负向边界。`npm run build` 会先跑测试再检查产物。
- 切换页为全部 18 套设计提供预览；`html-only` 的预览是自包含白纸式原生文档碎片，
  不改变正式页零 CSS / JS 的产物契约。
- 共享文档更正“隐藏菜单 DOM 可作为无 JS 语言回退”的错误表述；`html-only` 由原生
  导航提供语言入口，`styled` 的既有缺口如实保留。

## 验证结论

- `npm run build` 绿：`astro check` 0 错误 / 0 警告 / 1 条既有 `lexicon` hint；
  **81 页**，HTML-only 门禁 20/20、3 个语言页通过。
- 两套新设计的 `impeccable detect` 均为 `[]`。
- `homepage99` 在 1440 / 1280 保持三区布局，375px 与 320px 无横向溢出；系统字体、
  表格语义与窄屏 caption、共享菜单、日语页与 reduced-motion 均已实测。
- `html-only` 在 1440 / 375 / 320、无 JS、禁用 CSS 与键盘导航下内容完整；
  正式产物 0 `<style>` / 0 `<script>` / 0 stylesheet / 0 内联 `style`。
- 切换页实测 **18 张卡 / 18 个预览**；`html-only` 预览无焦点元素、文字不进入卡片
  可访问名；切换页聚合 CSS 为 **58 050 B**。
- `BASE_PATH=/demo` 与 `manualSwitch:false` 均已构建验证；配置按原字节恢复。

## 未覆盖

- 真机 iOS / Android、Safari / Firefox、横屏与 200% 缩放未实测。
- `styled` 设计页无 JS 时仍没有菜单语言入口；这是既有取舍，未在本版本修复。
- `messages.ts` 的动态 locale 完整性、`_draft` 注册不对称仍为既有缺口。
