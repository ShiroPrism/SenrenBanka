# 0.4.1（2026-10-10）两处动效修正：oxide 页脚波形同步流动、terminal 光标贴齐字面底部

## 变更

- **oxide**：页脚小波形补上 `.ox-wave-track`（v0.4.0 仅顶部波形有流动轨道、页脚静态）——两处节奏一致（同一 32s linear 循环、4 份无缝拼接）。仅 `Page.astro` 结构变化，复用既有 `.ox-wave-track` 规则；减动态时两者都静止。
- **terminal**：块状光标自"基线对齐"改为"底边与字面底部对齐"（`transform: translateY(0.15em)`）——基线对齐会让光标整体浮在字面之上（实测底边停在基线 191.55px，而字面墨迹底部在 196.55px）。修正后底边 197.31px、与字面底部齐平；该位移是静态 transform，减动态下仍保持（仅闪烁按约定停止）。`DESIGN.md` Shapes 与 Cursor 章节同步修订。
