## 成果

- 404 保持**单份 `dist/404.html`**，不再固定按默认 Locale 渲染；构建期预渲染全部 Locale 的正文、
  返回入口 / 全部设计 / 默认设计链接，默认区块在无 JavaScript 时可见。
- `<head>` 内联脚本在首屏前按「请求路径首段 → Locale preference → 浏览器语言 → 默认 Locale」
  选择展示语言；设置 `html[lang]`、`data-404-locale`（Locale path）与本地化 `<title>`，CSS 只显示
  对应区块。未配置的路径语言按无路径语言回退；非法偏好忽略，不写 / 不删偏好。
- 共享操作菜单仍只有一份 DOM；新增 Locale variants，运行时同步 404 菜单标签、分组、Toast、
  aria 名称、当前语言勾选、随机目标、全部设计 href 与分享标题。404 菜单语言项继续指向目标
  Locale 入口页；用户显式点击时仍写入语言偏好。
- 无 JS、`manualSwitch:false`、单语言配置与 `BASE_PATH=/demo` 均保留明确降级 / 分支行为；
  设计页、字体与视觉样式未改动。
- 新增 `src/lib/not-found.ts`、`scripts/not-found-locale.test.mjs`；更新 404 页面、共享菜单运行时 /
  组件、`CONTEXT.md`、ADR 0025、SPEC/README、规则、验证记录与 `docs/README.md`。
- 版本升到 **0.22.1**。
