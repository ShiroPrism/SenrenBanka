# 0.5.0（2026-10-10）桌面右键快捷操作菜单：可见切换入口整体替换为共享 ContextMenu

## 变更

- **新增共享组件与运行时**：`src/components/ContextMenu.astro`（中性 chrome：页眉「SENRENBANKA · 当前设计」+ 页面操作组 + 设计操作组；`<style is:inline>`，不新增 `<link>`）+ `src/lib/context-menu.ts`（打开 / 关闭 / 视口翻转定位、键盘操作、动作执行、随机语义、Toast 反馈）。菜单项：重新加载 / 回到页面顶部 / 复制当前页面链接 / 打印·保存 PDF / 分享页面 ｜ 随机一个设计 / 切换设计…。
- **数据层**：`src/lib/site.ts` 的 `DesignView` 以 `contextMenu` 取代原 `switcher` 字段（构建期派生：当前设计、目标池（`withBase()` href）、模式 / `cacheHours` / `avoidRepeat` / `storageKey`、分享标题；`manualSwitch:false` → `enabled:false`）。
- **四套设计**：删除全部可见旧入口共 6 处（editorial 导航 + 页脚、terminal chrome 条 + 页脚、oxide / fast 页脚）与专用 CSS（`.ed-switch` / `.tm-chrome-switch` / `.ox-switch` / `.fs-footer-link` 及各处 `pointer: coarse` 命中块条目）；`manualSwitch` 时在 `<body>` 末尾接入 `<ContextMenu config={view.contextMenu} />`。
- **交互规则**：仅 `(hover: hover) and (pointer: fine)` 桌面环境启用（内联能力门控 + 动态 `import()`，触屏不加载菜单逻辑）；链接 / 图片 / 输入控件 / 可编辑区 / 已选中文字 / 触屏来源一律保留浏览器原生菜单；`Shift+F10` / 上下文菜单键可打开；↑↓/Home/End 移动、Enter/Space 激活、Esc 关闭归还焦点、Tab 关闭不困焦点；鼠标打开不预高亮、键盘打开显示焦点环。移动端不提供菜单、不模拟长按、不保留任何替代入口。
- **随机语义**：完全复用既有存储契约（`storageKey`、`{ designId, expiresAt }`、`withBase()`）；必须排除当前设计，`avoidRepeat` 时再尽量排除上次；仅一套启用设计时该项 `aria-disabled`；写入后直接导航目标固定 URL（不回根路径）；打开菜单 / 页面加载不写存储。
- **降级与反馈**：复制 = Clipboard API → `execCommand` 同步降级 → 失败 Toast；分享 = 成功 / `AbortError` 取消 / 失败三态 Toast，`navigator.share` 不可用时移除该项（不留无效项）；`localStorage` 不可用 / 数据损坏均容错。
- **文档**：`AGENTS.md`（数据接口、切换入口规范、图标约定、已知坑 ×2、评审清单）、`SPEC.md`（Q4 / §3.2-14 / §6.4 / §7.2 表注 / §7.5 重写 / §9 / §11 / §13-14 / §14）、`docs/verification/shared.md`（v0.5.0 验证记录）、`CONTEXT.md`（Project chrome / Context menu / Toast）、`docs/adr/0004-context-menu-replaces-visible-switch.md`（决策与被否决选项）；editorial / terminal 自产 `DESIGN.md` 同步（oxide / fast 厂商快照未修改，偏差记录于 ADR 0004 与 `docs/designs/*/ADAPTATION.md`）。

## 验证

- 构建 7 页绿（`astro check` 0 错误 0 警告 0 提示）；检测器 editorial / terminal / fast 零发现、oxide 仅既知 `codex-grid-background` advisory（同时构成有效性反证）。
- 产物：四设计页各恰 1 条自身 CSS 链接 + 菜单样式内联；根页 / 切换页 / 404 零菜单字节；运行时 chunk（`context-menu.*.js`）独立、无 `modulepreload`；`BASE_PATH=/demo` 下配置 JSON / 复制结果 / 随机导航 / 切换页链接全链路带前缀。
- 桌面实测（1280×800 Chromium，四套设计）：菜单打开 / 视口边缘自动翻转；再次右键 / 外部左键 / 滚动 / 尺寸变化 / Esc 关闭；`Shift+F10` 打开且首项聚焦、鼠标打开聚焦容器；↑↓ 遍历、Enter 激活（回顶 796→0）、Tab 关闭；`role` / `aria-label` / `aria-disabled` / 图标 `aria-hidden` 齐备；console 0、仅同源请求。
- 动作：复制（API 剪贴板回读正确；真实 `execCommand` 降级回读正确；双失败 → 错误 Toast）；分享三态 Toast；重载（sessionStorage 计数 1→2）；打印（stub 计数 1）；随机（排除当前 + `avoidRepeat` 排除上次、`expiresAt≈now+24h`、直达固定 URL 不覆盖存储、fixed 模式写 `expiresAt:null` 且根路径尊重手选）；单启用设计 → 该项 `aria-disabled` 且强制点击不导航。
- 配置矩阵：`manualSwitch:false` → 6 页构建、`/designs/` 404、设计页零菜单 / 零脚本、右键不拦截；375×812 触控仿真 → 无菜单、程序化 contextmenu 无响应、菜单 chunk 请求数 0、无横向溢出、无可见切换入口。
- 验证期暴露并修复 4 处真实缺陷：① 右键 pointerdown 先于 contextmenu 关闭导致"再次右键重新打开"（改为仅左键 pointerdown 收起，右键语义由 contextmenu 承担）；② 降级复制解构 `execCommand` 裸调用抛 `Illegal invocation`（改为以 `document` 为 `this` 调用）；③ 鼠标打开时首项出现键盘焦点环（改为鼠标聚焦容器 / 键盘才聚焦首项并显示 `data-cm-key` 焦点环）；④ 亮色 eyebrow `#8e8e93` 对比度 3.26 不达标（调深为 `#6f6f74`，实测 5.00；菜单色板其余档 5.15–17.01，暗色 6.04–14.52，Toast 13.73 / 错误档 9.36）。截图归档：`C:\Users\lovelive\.trae-cn\trae-browser-screenshots\`（`verify-050-<id>-menu.png`、`verify-050-editorial-keyboard.png`、`verify-050-terminal-dark.png`、`verify-050-editorial-375.png`、`verify-050-editorial-menu-final.png`）。
