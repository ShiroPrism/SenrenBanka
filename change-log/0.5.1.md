# 0.5.1（2026-10-11）右键菜单顶部重设计：单行身份条 + 内容自适应宽度

## 变更

- **顶部重设计**（项目所有者反馈：两行头部「SENRENBANKA · EDITORIAL / 当前设计」意义不明、宽度过宽）：移除品牌 eyebrow 与两行头，改为**单行身份条**——设计强调色圆点（`design.json.accent`，与 `/designs/` 切换页芯片同源；以 `--cm-accent` 内联传入，缺省中性灰）+ 设计名（0.8125rem / 600）+ 右对齐淡化标签「当前设计」；头部不再 `aria-hidden`（承载真实信息），圆点装饰性 `aria-hidden`。
- **宽度**：`width: max-content` + `min-width: 13.5rem` + `max-width: min(16.5rem, calc(100vw - 1.5rem))`——实测四套设计均 **216px**（原 304px），右缘空白消失；条目 gap / 内边距与分隔线边距小幅收紧（菜单高度 352 → 326px）。
- **数据层**：`ContextMenuConfig` 增加可选 `accent`（`buildDesignView` 从 `design.meta.accent` 派生）；运行时配置 JSON 不含该字段（纯呈现数据）。
- **文档**：SPEC §6.4（`contextMenu` 字段说明）、§18（本条记录）同步；`change-log/0.5.0.md` 的旧头部描述为历史记录，不改写。
