# 0.15.1 — receipt 桌面折叠双栏

2026-10-19

## 背景

receipt 在 1024px 以上同时输出三种语言的 480px 小票，1440 视口总宽超过 1600px，
既触发页面横向滚动，也让初始视口只看到部分票据。改为单张当前语言票据后，
桌面需要新的宽度与阅读节奏，而不是简单放大一张 30rem 纸。

## 成果

- `Page.astro` 改用 `loadDesignView`，只渲染当前语言的一份票据；语言切换继续由共享操作菜单承担。
- `Ticket.astro` 删除 `isCurrent` / `is-primary`，正文五枚 section 组成单一 `.rc-fold-body`；
  票头、简介与页脚继续横跨整张纸。
- `style.css` 在 `>=1024px` 使用 `column-count: 2` 自动平衡双栏，`column-rule` 作为 1px 折痕；
  纸张宽度上限 72rem，1440 实测 1152px，左右台面 137 / 151px。`<1024px` 回到 30rem 单栏。
- 英文等叙述型任期改用票据等宽字，纯日期 / 数字任期保留 DSEG7；长文本与 URL 增加换行保护。
- `messages.ts` 三语言删除旧三联专用的 `railTitle`。
- `DESIGN.md` 将 Triplicate Rule 更新为 Folded Sheet Rule；`docs/verification/receipt.md` 改写为当前验证状态。
- 共享文档中把 receipt 当作三联示例的过时描述已同步清理。

## 验证结论

- `npm run build` 绿：`astro check` 0 错误 / 0 警告 / 1 条既有提示（`lexicon/Page.astro`），73 页。
- 1440：单票据、双栏、`scrollWidth 1425 <= 1440`，`column-count: 2`、`column-gap 100.8px`，
  纸内无越界；1024 仍为双栏且无横向滚动；1000 为 480px 单栏。
- 375×812 触控仿真：无横向溢出、共享菜单可开合、链接命中 45px。
- 三语言 `<html lang>` / canonical / robots 正确；菜单语言项保持 receipt 目标；中→日实测落点为 `/ja/receipt/`。
- `reduced-motion` / 无 IO / IO 抛错 / 无 JS 四情形内容均可见；6 个 reveal 区块最终全部显示。
- impeccable 检测器 `src/designs/receipt` = `[]`；三语言共用单一 13,498 B 样式文件，无其他设计选择器。
