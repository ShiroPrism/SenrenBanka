# 0.3.1（2026-10-10）链接列表面 100% 标记（修正"半用"不一致）

项目所有者裁定「要么不用，要么全用」：同一链接列表面内不允许部分链接有标记、部分裸链接。修订决策见 `docs/adr/0002-icon-and-brand-mark-strategy.md`「修订（v0.3.1）」节。

## 变更

- **通用功能图标 `Globe` 作为未映射 / 缺省 slug 的标记**（editorial / oxide / fast；terminal 的 `→` 原本即全量）——「博客」链接获得图标，纯文本回退否决。
- **oxide**：CHANNELS 的 Email / 博客由 `▸` 占位改为功能图标（Mail / Globe，lucide outlined、1.5 描边、0.8em，贴厂商「outlined variants」语言）；品牌仍为填充 mark。`▸` 保留于页脚联系与切换器（列表面之外的原生 affordance）。
- **editorial**：Elsewhere 的「博客」补 Globe（灰墨、0.85em、1.5 描边，与 GitHub mark 同槽）。
- **fast**：hero 按钮「博客」补 Globe（1em、品牌蓝，与 Mail / mark 同槽）。
- **边界**：列表面之外的链接（页脚邀请 / Contact CTA / 切换器）保持各设计原生 affordance，不受"全用"约束。
- **文档**：ADR 0002 修订节、`CONTEXT.md` 术语（icon fallback 语义更新）、`AGENTS.md` 约定同步、editorial `DESIGN.md` 章节更新；厂商 `DESIGN.md`（oxide / fast）未修改。
