# 0.2.0（2026-10-10）页面进入动画与滚动进入视口动画

为规范授权的设计加入入场与滚动显现动效，并建立一套"只触发、不规定视觉"的共享机制（决策见 `docs/adr/0001-motion-reveal-mechanism.md`）。

## 新增

- **共享滚动显现机制**（`src/lib/reveal.ts` + `src/components/Reveal.astro`）
  - `IntersectionObserver` 观察 `[data-reveal]`，首次进入视口置 `[data-reveal-in]` 并 `unobserve`（只播一次）
  - 内联 boot 同步门控：仅当「非 `prefers-reduced-motion: reduce` 且支持 `IntersectionObserver`」时给 `<html>` 打 `data-reveal-ready`
  - 只含 JS、不 import 任何 CSS，不触发多设计 CSS 聚合
- **oxide 动效**（厂商规范已授权 Motion）：首屏入场（hero 4 项，纯 CSS，260ms `ease-out`，40ms 错落）+ 滚动显现（`.ox-columns` 整块、项目/经历行 30ms 错落，上限 5 行）
- **fast 动效**：首屏入场（hero 4 项，纯 CSS，复用 `--fast-duration-normal` / `--fast-curve-easy-ease`，30ms 错落）+ 滚动显现（各 `.fs-section` 整块）
- **文档**：`CONTEXT.md`（术语：entrance animation / reveal / reveal gate）、`docs/adr/0001-motion-reveal-mechanism.md`、`AGENTS.md` 新增"动效（Motion）"约定
- **验证流程同步**：`design-page-verify` skill 新增**步骤 4b 动效实测**（门控 / 首屏 animation / 滚动到底全部揭示 / **跳转滚动兜底**）、**步骤 5b 降级与可访问性**（reduced-motion / 无 JS / 无 IO / 脚本抛错 → 隐藏元素恒为 0）与对应通过标准；触发条件扩展为含 `src/lib/` / `src/components/`；触控仿真补充 `browser_run_code_unsafe` 直建上下文的方式，并明确"无动效设计显式跳过而非漏测"
- **skill 二轮硬化（演练暴露）**：前置补"端口被占用 → 清 4321 再重启 preview"；步骤 4 的 a11y 项改为**可判定**（每个分区必须有可访问名称、计数 > 0；装饰符号不得进入链接可访问名）；通过标准新增 a11y 行。`AGENTS.md`「入库范围」写明：skill 唯一位置是 `.agents/skills/design-page-verify/SKILL.md`（本轮曾因 `.trae/` 副本失配导致更新未生效，已修；该副本同日删除，此后单副本、改完即生效）

## 修复（验证期暴露的真实缺陷）

- **跳转式滚动导致内容永久隐藏**：元素"从视口下方直接跳到上方"不跨越 `IntersectionObserver` 阈值 → 无通知 → 永不揭示（实测跳到底部 6 个目标只揭示 4 个）。已加滚动兜底补揭示已到达视口的目标（复测 6/6）。
- **"脚本失败"契约缺口**：门控已写入而模块未执行/抛错时内容会永久隐藏。已加内联计时安全网（2s 未初始化则撤销门控并全部揭示）+ 模块 `try/catch` 兜底。
- **oxide 触控命中区缺失**（既存缺陷，非遗留自动效改动）：375px 实测 `.ox-link` 14.4px、`.ox-switch` 39.4px。已补 `@media (pointer: coarse)` 块（`padding-block: 0.95rem`；`.ox-row-title a` 的 border 下划线在触控下改用同色 `text-decoration`），复测 minHit 44.8px。
- **oxide 两项既存 a11y 缺口**（由 v0.2.0 后的 skill 演练暴露）：① 分区无可访问名称（实测 `aria-label|aria-labelledby` 计数 0）→ 为 hero / channels / capabilities / deployments / operations / footer 补 `aria-labelledby` 指向同区可见标签（`.ox-columns` 改为布局 `<div>`，两栏升为具名 `<section>`，CSS 无需改动）；② 装饰符号进入可访问名（`▸GitHub` / `▸Email`）→ `●` 与全部 `▸` 加 `aria-hidden`，切换入口改 `aria-label="切换设计 / Switch design"`。复测：`aria-labelledby` 6 处 + `aria-label` 1 处、`aria-hidden` 8 处、4/4 箭头隐藏；桌面 `.ox-columns` 两列、375px 单列、触控命中 44.8px、跳转滚动后隐藏元素 0、console 0 —— 布局与动效无回归。

## 已知限制

- 真机（iOS / Android）与 Safari / Firefox 引擎未实测；`prefers-reduced-motion` / 无 JS / 无 `IntersectionObserver` 降级基于 Chromium 仿真
- 内联计时安全网路径（模块完全未执行）未单独仿真，但模块由 Astro 内联进 HTML、紧随 boot 执行
- 支持 `IntersectionObserver` 但禁用页面脚本的极端组合下，门控不成立 → 内容保持可见（设计如此）
