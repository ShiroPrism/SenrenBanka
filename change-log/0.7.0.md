# 0.7.0（2026-10-11）批次 2：新增 Material 3（汇编）与 Kern（复刻席首套）

## 成果

- **新增第 5 套设计 `material3`**（Google Material 3，`official-docs-derived` 汇编）：整合 m3.material.io 官方指南（CC BY 4.0）与 material-components/material-web v0.192 token 源码（Apache-2.0）为一份自有行文规范——baseline 色彩角色（浅 / 深双模值、tonal 面层沿革、三层对比度、状态层 8/10/10/16）、15 档型阶（Roboto）、圆角标尺（0–28 / full）、层级 0–5（tonal 色优先、阴影按需）、emphasized 动效全表（缓动 / 时长 / 建议配对）、Material Symbols 四轴、窗口尺寸类与 4dp 间距、sentence case 内容规则；逐来源附录 + 双许可全文（`SOURCE-LICENSE.txt` 626 行）。**整合完成即冻结**；商标边界、Roboto Flex 打包、vendored Material Symbols SVG ×2、web 阴影配方、深浅双模见 `docs/designs/material3/ADAPTATION.md`。
- **页面实现**：紫 tonal 色系 + 大圆角（4–28px）+ level1/2 阴影 + 状态层近似（hover 8% / press 10%）+ **`prefers-color-scheme` 深浅双模**（M3 baseline 深色映射，现有设计首例）+ 600 / 840 窗口尺寸类断点。
- **新增第 6 套设计 `kern`**（复刻席首套，`third-party-analysis`）：对 Vercel Geist 视觉语言的**非官方致敬复刻**——自撰规范（impeccable 家格式）+ 纯黑白高对比 + **发丝线网格骨架**（竖引导线 ×2 / 分区规则线 / 交点 `+` 十字号）+ 共享边界单元网格 + Geist 无衬线 / 等宽双声部 + 反转式主行动 + 零阴影平面。id / displayName 按 SPEC §4.4 命名规则逐套提案定稿（方案 A，2026-10-11）；不复用任何上游文本 / 素材 / 品牌资产。
- **复刻席机制首次走通**：命名提案 → 自撰规范 → 实现 → 全流程验证；来源形态三类（快照 / 汇编 / 复刻）全部有实物（ADR 0005 所述闭环补齐）。
