# 0.14.1 — 切换页卡片几何与间距修正

2026-10-19（补记；提交 `9a80adc`）

## 背景

0.14.0 全铺后，切换页卡片仍会因描述只有一行而在底部留下空洞，卡片之间的上下间距也不够稳定。该修正已随 `9a80adc` 发布，但当时遗漏了独立版本记录。

## 成果

- 预览容器统一为 `16 / 10` 画幅；卡片固定为「预览 → 标题 → 两行描述」三段式纵向结构，不再靠 `stretch` 掩盖单行描述造成的底部空洞。
- 栅格间距增至 `1.5rem`，桌面每行最多 3 张、`<=60rem` 两列、`<=48rem` 单列。
- 1536 / 1280 / 960 / 375 四档实机复验：16 张卡片尺寸一致、上下间距正常、无横向溢出。
- `AGENTS.md`、`SPEC.md`、`docs/verification/shared.md` 与 `change-log/0.14.0.md` 同步补记卡片几何契约。

## 验证结论

- `npm run check` 0 错误 / 0 警告 / 1 条既有提示；`npm run build` 73 页绿。
- 1536px 下 16/16 卡片均约 `379 × 333px`，预览均约 `353 × 221px`，描述区统一两行高。
- 切换页仍为单条自身 CSS，0 preflight、0 设计整页选择器、0 `:root` 设计令牌。

## 未覆盖

- 真机 iOS / Android 与 Safari / Firefox 引擎未实测；本轮几何复验基于 Chromium 桌面与 375px 触控仿真。
