# Decision — Shelf 退役（2026-11-05）

## 结论

`11-05-shelf-design` **不合并、不进入第 29 套**。首轮视觉评审后退役；`src/designs/shelf/` 已删除，`descriptions.ts` 与字体计数脚本已回滚，仓库恢复为 28 套（27 styled + 1 html-only）。

## 为什么退役

- **概念层级错了**：把包装当成了内容本体，而不是视觉皮肤。`experience` → “生产信息”、`links` → “购买渠道”、`skills` → “配料”，第一次访问者必须先解码主题才能找到项目 / 经历 / 技能 / 联系。
- **直接误导求职状态**：`非卖品` 会被读成“不招人”，`净含量 1 人` 把人当货；即使把 h2 改回“经历 / 项目”，这些框架仍在说“我是商品”。
- **不是单套问题**：`magical-girl` 的“魔法道具 / 星轨章回 / 变身年表 / 技能封印 / 蜡封信笺”等，以及 `zine`、`pixel-pet-rpg`、`radio`、`pager`、`tape`、`archive`、`little-forest` 等主题，也把主分区替换成主题词。一次访问者同样需要解码。

## 已验证 / 未验证

- 已做首轮视觉：1440 / 768 / 375 全页截图；名字 WordArt（黄填充 + 黑描边 + 红偏移）与版面成立；375 无横向溢出；Reveal 滚动到底隐藏元素 0。
- 未做完整 5 语言 / 对比度 / 减动态 / 无 JS / 预览 / 字体子集 / dist 验证；退役后不再补。
- 未新增字体发布；只用了现有 `Inter` / `Noto Sans TC` / `Zhuque` / `Gothic A1` / `JetBrains Mono`。

## 留下的约束

- 规则：`docs/rules/design-contract.md`「信息架构与主题文案」——主分区必须保留「简介 / 项目 / 经历 / 技能 / 联系」或同义标准词；主题词只能做副标题 / 次级词 / 装饰；禁止商品化 / 误导求职状态的核心文案。
- SPEC：`SPEC.md` §4.4.1 记录 2026-11-05 退役原因。
- 后续：按新规则审计既有主题的主分区标签；审计 / 修复应另开任务，不在本任务内顺手改。

## 如果将来重做

若仍想做“红黄黑 / 90s 商品包装”的视觉冲击，只保留**视觉皮肤**：标准 h2（简介 / 项目 / 经历 / 技能 / 联系）+ 主题副标题；删除“非卖品 / 净含量 / 配料 / 生产信息 / 购买渠道”等商品化主文案。更合适的求职隐喻是「人事档案 / 作品集盒」，不是「货架上的商品」。
