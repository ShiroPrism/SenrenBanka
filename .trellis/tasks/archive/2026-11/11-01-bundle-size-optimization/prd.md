# 优化打包体积：字体语料按引用页 + 跳转页样式精简

## Goal

在不改变任何设计页展示、字体选择、交互与跳转行为的前提下，把 `dist` 从 **8,855,728 B（8.45 MiB）** 降到 **≤ 7.75 MB（约 7.39 MiB）**，为 10 MiB 硬门禁留出 ≥ 2.9 MiB 余量。

## Background

2026-11-01 对当前产物实测：

| 项目 | 现状 |
|---|---:|
| `dist` 总量 | 8,855,728 B |
| HTML | 4,148,031 B |
| 字体 | 3,686,028 B（45 个 woff2，0 孤儿） |
| CSS | 705,504 B |
| PNG | 302,730 B |
| JS | 11,747 B |

两项可回收空间已完成实测，不是估算：

- **字体**：8 个非 Hangul core 族当前用全站 1833 码位语料，子集合计 2,590,852 B；按“实际引用该族的页面”限定语料后实验预估 **1,491,552 B**，实现后实测 **1,502,884 B**；含 6 个 Hangul 族的 14 族合计 **1,625,116 B**（基线 2,774,444 B）。Hangul 族也从固定 454 字改为按引用页（250–297 字），`fonts:audit` 0 部署缺口。
- **旧路径跳转页**：28 个 `LegacyRedirect` 产物共 119,080 B，其中内联样式 104,580 B；每页 4,248 B 中样式 3,735 B，实际使用规则仅 1,091 B，死规则 2,059 B/页，含注释可回收约 2,644 B/页，合计约 **74 KB**（保守 ≥ 56 KB）。

用户已明确：**头像不改**（PNG 转 WebP 方案不做）；菜单图标 sprite、内联脚本外置也不在本轮范围。

## Scope

**In scope**

- `fonts:subset` 的语料粒度从“全站”改为“按字体族实际被引用的页面”。
- `LegacyRedirect` 只内联实际使用的少量样式，去掉列表网格、预览、语言切换器等死规则。
- 同步更新 `SPEC.md`、`docs/rules/operations.md`、ADR、`docs/verification/` 与字体管线测试。

**Out of scope**

- 头像 PNG/WebP 转换、图片管线调整。
- 操作菜单图标 sprite、内联脚本外置/压缩。
- 设计页 HTML、设计 CSS、文案、字体选择或字体目录（catalog/lock/generated）变更。
- 视觉样式改版、切换页预览增删、任何新运行时请求。

## Child Tasks

| 子任务 | 交付物 | 预估收益 | 风险 |
|---|---|---:|---|
| `11-01-legacy-redirect-style-trim` | `LegacyRedirect` 专用精简样式 | ≥ 56 KB | 低 |
| `11-01-font-subset-page-corpus` | 按引用页语料的字体子集管线 | 1,099,300 B | 中 |

建议实施顺序：先做跳转页（低风险快速验证流程），再做字体语料。两者无代码依赖；父子关系只用于整体验收与集成复核。

## Cross-child Requirements

- R1 全部 175 个页面的可见文本、字体选择、布局与交互与改动前一致；不得出现缺字回退或排版变化。
- R2 字体语料仍只从最终 `dist` 派生，不得引入手写语料清单或从源码另行推导。
- R3 跳转页的 `meta refresh`、canonical、noindex、无 JS 降级与可见链接保持不变；根页 / 语言入口 / 切换页 / 404 的产物逐字节不变。
- R4 不新增运行时资源、不改变设计 CSS、不触碰头像与菜单脚本。
- R5 `npm run build`、`npm test`、`fonts:audit`、`design-page-verify` 全部通过，并在 `docs/verification/` 记录实测数据。

## Risks

- **字体语料漏字**：按引用页收窄语料后，若页面存在运行期才注入且未出现在共享 JS/CSS 中的文本，可能缺字。缓解：共享非 HTML 资源全量入语料；页面 HTML 原始文本（含属性、脚本、样式）全量入语料；`fonts:audit` 按真实 cmap 逐页校验。
- **报告契约变化**：`subset-report.json` 增加 per-family 语料字段属于内部 schema 变化；缓解：同步更新测试与文档，报告不入库。
- **跳转页样式回归**：只裁剪规则，不改结构；缓解：保留实际使用的 9 条规则并做亮/暗色截图对比，完整基础设施页做逐字节基线比对。
