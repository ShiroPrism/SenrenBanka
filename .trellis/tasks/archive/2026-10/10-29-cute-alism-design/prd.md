# Cute-alism 硬核糖果可爱设计

## Goal

新增 `cute-alism`：以粗黑描边、硬边阴影、几何贴纸、高对比糖果色和不对称拼贴构成具有平面设计张力的完整主页。

## Requirements

- 整页使用统一的几何拼贴语法，不是单张海报或“新粗野主义卡片”换色。
- 巨型姓名/色块形成主视觉；简介、链接、项目、经历、技能、联系分别转为切角色块、标签条、拼贴网格、阶梯色带、徽章和包装背标。
- 全部核心与三语非空可选字段呈现；不得用 Emoji 或图标替代真实信息。
- 禁止渐层、毛玻璃、柔和阴影；使用扁平色块、黑描边、硬阴影。
- 字体为 `Fredoka`、`LXGW WenKai`、`Inter`，小标签可用既有 `League Mono`；不得用 `League Gothic` / `Blackout` 复刻 Poster。
- 不创建主题脚本；动效只用 CSS 步进/位移。
- 提供自包含 `Preview.astro`，呈现拼贴网格、粗描边姓名块和几何贴纸。

## Out of Scope

- 新 Profile 字段、外部素材、共享 JS、现有 Poster 风格的复刻。

## Acceptance Criteria

- [ ] 三语页面与全部非空字段呈现；标题、正文、链接状态清晰。
- [ ] 全页视觉重心、色块和组件状态属于同一系统，不是孤立贴纸堆。
- [ ] 桌面不对称构图与 375px 单列重排无横向溢出。
- [ ] 黑描边/硬阴影不遮挡文字，对比度 ≥4.5:1，焦点清晰。
- [ ] 无主题 JS、无渐变/玻璃/柔和阴影、无 Poster 字体组合。
- [ ] CSS 使用 `.cal` / `.cal-` 命名空间；预览不污染正式页。
- [ ] 完成主题级 `design-page-verify`、检测器、截图和例外记录。
