# 切换页设计预览全铺 + 三列响应式栅格

> 承接已归档任务 `10-18-switcher-design-preview`（3 套原型 + 架构定稿）。
> 用户裁定：**铺开范围改为 16 套全铺**；同时改造切换页栅格——桌面按窗口宽度横向排列、每行最多 3 个卡片，移动端保持单列。

## Goal

切换页 `/{locale}/designs/` 目前只有 3 套预览，其余 13 套仍是「accent 色点 + 文字」卡片。本次为**全部 16 套设计**补齐 `Preview.astro` 与令牌抽取，并把切换页从「单列长列表」改为**按窗口宽度自适应、每行最多 3 张**的栅格；移动端仍为单列。

## Confirmed decisions（2026-10-19，用户授权「按你的判断做」）

| 决策 | 取值 | 依据 |
|---|---|---|
| 铺开范围 | **16 套全铺** | 用户明确指令 |
| 内容区宽度 | `42rem` → **`74rem`** | 三列需每列约 20–24rem；1280px 视口仍留侧边距 |
| 栅格策略 | `repeat(3, minmax(0, 1fr))`，`<=60rem` 2 列、`<=48rem` 1 列 | 每行最多 3 张；中屏 2 列、移动端单列 |
| 移动端 | **单列**（`< 48rem` 强制 1 列） | 用户要求 |
| 预览文字量 | 姓名 + 一行副标题 + 最多 2 条链接 | 与已验收 3 套一致，控制 HTML 膨胀 |
| 令牌抽取 | 每套私有 `tokens.css`，命名空间类作用域 | 沿用 `10-18` 三条硬约束 |

## Requirements

- **R1 全铺**：其余 13 套（`editorial` / `fax` / `frost` / `govuk` / `kern` / `lexicon` / `material3` / `oxide` / `pager` / `poster` / `radio` / `receipt` / `tape`）各新增 `Preview.astro`，体现该设计**最有辨识度的布局骨架、字体角色、配色与签名装饰**，不得退化为通用卡片。
- **R2 令牌抽取**：各设计调色板抽入同目录 `tokens.css`，作用域为命名空间类（如 `:is(.ed, .ed-pv)`）；**`pager` 的 `:root` 必须迁移**（唯一剩余的全局令牌泄漏源）。正式页产物须与改动前**字节级等价**。
- **R3 隔离硬约束**（沿用 `10-18` 实测结论）：
  - `Preview.astro` **不得** import 本设计 `style.css`；不得声明 `<Font>`；不得含 `:root`。
  - 预览样式只出现在切换页；任一设计页不得出现预览选择器。
  - 切换页不新增 Tailwind preflight。
  - `style.css` 必须 `@source not "./Preview.astro";`。
- **R4 字体**：预览导出 `fonts`（`CssVariable[]`），切换页按族去重后页面级声明一次；`@font-face` 随族数而非预览数增长。
- **R5 栅格**：桌面按窗口宽度横向排列、**每行最多 3 张**；移动端单列；375px 无横向溢出。
- **R6 回退**：无 `Preview.astro` 时仍回退 accent 色点卡片；机制保留且不得破坏。
- **R7 静态兼容**：不引入运行时 JS、服务器依赖或截图资产。
- **R8 检测器**：新增文件 `impeccable detect` 0 条，或将缩略档位登记进 `DESIGN.md` / `ADAPTATION.md` 后归零。

## Acceptance Criteria

- [ ] **A1** `npm run build` 绿，页数不变（73 页）；`astro check` 0 错误 / 0 警告（既有 1 条 hint 不计）。
- [ ] **A2** 16 套设计均有 `Preview.astro`，切换页渲染 **16 个预览**（三语言一致）。
- [ ] **A3** 切换页恰 1 条样式表；0 preflight；0 任一设计整页选择器；0 `:root` 设计令牌。
- [ ] **A4** 16 套 × 3 语言设计页：0 预览选择器，每页恰 1 条自身 CSS。
- [ ] **A5** 每套设计正式页产物与改动前**字节级等价**（归一化 CSS 文件名后 sha256 相等）。
- [ ] **A6** `@font-face` 数量 = 去重族数；记录实测值；无重复族。
- [ ] **A7** 栅格：1536px 每行 3 张；1024px 2–3 张；375px 1 张且 0 横向溢出（三语言）。
- [ ] **A8** 无障碍：预览 `aria-hidden`、0 可聚焦元素、不进入卡片可访问名（CDP 无障碍树 + Tab 走查）。
- [ ] **A9** 视觉：16 套逐套对照正式页「一眼可认」，不得通用卡片化。
- [ ] **A10** 检测器 0 条（或全部已登记）；reduced-motion 动画全停、内容可见；console 0 错误。
- [ ] **A11** 成本实测并记录：切换页 CSS / HTML / DOM 节点 / 字体声明数。
