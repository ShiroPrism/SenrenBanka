# Fairy Kei 复古玩具收藏箱设计

## Goal

新增 `fairy-kei` 独立 `styled design`：一只打开的复古少女玩具收藏盒，使用糖果色、收藏标签、包装卡纸、挂饰和多层陈列关系组织同一份三语 Profile。

## Requirements

- 首屏是玩具收藏场景，而不是普通粉色卡片页；姓名、头像、定位、简介和链接在场景中拥有明确层级。
- 头像窗/姓名挂牌为中心；链接为悬挂饰品；简介为包装卡；项目为玩具盒；经历为丝带轴；技能为贴纸册；联系为便签。
- 全部核心字段和三语非空可选区块必须渲染；不得虚构资料。
- 使用 `Fredoka`、`LXGW WenKai`、`Inter`；六项字体记录写入 `DESIGN.md`。
- 不创建主题脚本；使用 CSS 和原生 HTML，必要时用 `details` 表现抽屉。
- 视觉非目标：通用粉色卡片流、Emoji/爱心堆叠、Sticker Diary 的笔记本跨页、Tape/Archive 的桌面纸片器物。
- 必须提供自包含 `Preview.astro`，展示收藏盒、标签与糖果色视觉签名。

## Out of Scope

- 新 Profile 字段、主题专用数据、外部位图或新依赖。
- 修改共享注册、字体配置、描述索引、公共组件或其他设计。

## Acceptance Criteria

- [ ] 三语页面生成；core fields 和所有非空可选字段呈现。
- [ ] 桌面呈不对称收藏陈列，375px 按 DOM 顺序成为可读单列场景。
- [ ] `Fredoka` 拉丁标题、`LXGW` 中日文手写声部、`Inter` 正文均为真实字体栈并有系统回退。
- [ ] 无主题 JS；开盒/饰品/按压动效有减动态终态。
- [ ] 分区有可访问名称，装饰 `aria-hidden`，对比度 ≥4.5:1，触控目标 ≥44px。
- [ ] CSS 使用 `.fk` / `.fk-` 命名空间，预览不污染正式页。
- [ ] 完成主题级 `design-page-verify`，记录桌面、375px、字体、对比度和截图。
