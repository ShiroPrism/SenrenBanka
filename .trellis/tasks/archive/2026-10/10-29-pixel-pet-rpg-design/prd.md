# Pixel Pet RPG 像素宠物小镇设计

## Goal

新增 `pixel-pet-rpg`：一座可探索的可爱像素宠物小镇，以游戏 HUD、地图节点、物品栏和地点面板组织 Profile。

## Requirements

- 首屏具有像素场景与小镇地图，不使用现代卡片加像素字体。
- 顶部 HUD 只显示真实姓名/定位/装饰标记；地图节点对应资料、链接、项目、经历、技能、联系；链接为物品栏，项目为地图地点，经历为任务日志。
- 禁止虚构等级、HP、XP、完成率、成就或游戏统计；任何纯装饰状态必须显式 `aria-hidden`。
- 允许一个私有 `script.ts`，≤12KB gzip；地图节点必须是真实锚点，脚本仅增强当前地点切换与玩家标记。
- 无 JS 时所有地点内容按 DOM 顺序可见、可锚点跳转。
- 字体只使用既有 `Silkscreen`、`Ark Pixel 12px`、`Handjet`。
- 提供自包含 `Preview.astro`，呈现像素地图、HUD 和地点节点，不复制 Pager 设备壳。

## Out of Scope

- 真实游戏、存档、排行榜、统计数据、外部位图、Canvas-only 内容或共享 JS 引擎。

## Acceptance Criteria

- [ ] 三语页面与全部非空字段呈现；没有虚构游戏事实。
- [ ] 地图节点在无 JS 时为可用锚点；JS 成功时切换地点面板并同步可访问状态。
- [ ] 键盘可按顺序操作；焦点不被劫持；脚本失败恢复全部内容。
- [ ] 主题 JS ≤12KB gzip，无依赖、无 CSS import。
- [ ] 桌面场景构图与 375px 单列地图/面板无横向溢出。
- [ ] 装饰像素、扫描线和 HUD 标记不进入可访问名。
- [ ] CSS 使用 `.pxt` / `.pxt-` 命名空间；预览与正式页隔离。
- [ ] 完成主题级验证、JS 降级矩阵和截图记录。
