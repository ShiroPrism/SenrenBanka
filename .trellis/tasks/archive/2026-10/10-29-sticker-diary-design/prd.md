# Sticker Diary 手帐贴纸日记设计

## Goal

新增 `sticker-diary`：一本用户亲手制作的跨页手帐，使用纸张边缘、和纸胶带、手写批注、书签与轻微错位层叠组织完整 Profile。

## Requirements

- 桌面显示一册打开的手帐跨页；首跨页呈现身份、头像、定位、简介，后续跨页承载链接、项目、经历、技能与联系。
- 页边书签、上一页/下一页与键盘方向键可切换跨页。
- 允许一个私有 `script.ts`，≤12KB gzip；只管理跨页状态，不获取或生成内容。
- 无 JS、模块失败或初始化失败时所有跨页按 DOM 顺序展开为完整长文档。
- 字体为 `UglyTypist`（拉丁手写）、`LXGW WenKai`（中日文手写）、`Inter`（长正文）。
- 视觉非目标：Tape/Archive/Receipt 式桌面纸片、只有贴纸背景的普通卡片、牺牲阅读的长篇手写。
- 提供自包含 `Preview.astro`，呈现跨页、胶带、书签和手写层次。

## Out of Scope

- 新 Profile 字段、外部素材、共享交互运行时、修改共享配置或其他设计。

## Acceptance Criteria

- [ ] 三语六类资料完整呈现；无 JS 时全部区块可见、锚点和链接可用。
- [ ] JS 成功时书签、前后按钮与方向键均可切换；当前页 `aria-current` 正确，无焦点陷阱。
- [ ] 脚本初始化失败时恢复长文档；减动态取消翻页过渡但保留功能。
- [ ] 主题脚本 ≤12KB gzip，无依赖、无 CSS import、无内容门控。
- [ ] CSS 使用 `.sd` / `.sd-` 命名空间；预览不污染正式页。
- [ ] 桌面与 375px 无横向溢出，正文对比度和触控目标达标。
- [ ] 完成主题级 `design-page-verify` 和三种 JS 失败路径实测。
