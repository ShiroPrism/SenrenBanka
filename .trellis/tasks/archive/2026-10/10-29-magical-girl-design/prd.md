# Magical Girl 魔法少女档案设计

## Goal

新增 `magical-girl`：魔法少女角色档案与舞台登场页，使用原创星轨、丝带、魔法阵、网点和档案卡呈现完整 Profile。

## Requirements

- 首屏以姓名、头像/轮廓、定位、简介为视觉中心；头像缺失时仍成立。
- 链接为魔法道具，项目沿星轨成为章回，经历为变身年表，技能为封印，联系为蜡封信。
- 允许一个私有 `script.ts`，≤12KB gzip，只编排一次 0.8–1.2 秒的星轨/缎带/档案落位。
- 无 JS、脚本失败、减动态时不播放编排但所有内容立即处于最终态；脚本不得加覆盖层或阻塞正文。
- 不使用现成动漫角色立绘、品牌标识、外部位图或受版权保护素材。
- 字体为 `Fraunces Italic`、`LXGW WenKai`、`Inter`。
- 提供自包含 `Preview.astro`，呈现档案卡、星轨、丝带与封印视觉。

## Out of Scope

- 外部角色图、自动播放声音、全屏开场遮罩、主题共享 JS 引擎、修改共享文件。

## Acceptance Criteria

- [ ] 三语页面与全部非空字段呈现；无头像时身份布局完整。
- [ ] 星轨/缎带/档案编排 ≤1.2 秒、不阻塞正文、无声音/覆盖层。
- [ ] 无 JS、脚本失败、reduced-motion 时内容可见且无隐藏残留。
- [ ] 主题 JS ≤12KB gzip，无依赖、无 CSS import、无持续循环。
- [ ] 核心信息不被装饰遮挡；对比度、焦点、触控、标题层级达标。
- [ ] CSS 使用 `.mg` / `.mg-` 命名空间；预览不污染正式页。
- [ ] 完成主题级验证、脚本三路径、截图与检测器记录。
