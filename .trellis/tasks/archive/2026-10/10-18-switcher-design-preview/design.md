# design.md — 切换页设计预览：技术设计

> 本文件承载技术设计、边界、契约、取舍与本轮实测证据。
> 需求与验收见 `prd.md`；执行协议见 `implement.md`。
> **所有机制结论均为本机实测**（2026-10-18，Astro 7.3.8 / tailwindcss 4.3.3），探针已在验证后清除。

## 1. 现状基线（实测）

| 项 | 实测值 |
|---|---|
| 切换页产物（`dist/en/designs/index.html`） | 36KB HTML |
| 切换页样式表链接 | **0** |
| 切换页 `@font-face` | **0** |
| 切换页卡片 | 16 accent 色点 + 16 卡片 |
| 全站构建页数 | 73 |
| 每套设计编译 CSS | 9–16KB（含 4–5KB Tailwind 基线 + 4–11KB 设计规则） |
| 每套设计页链接的样式表 | **恰好 1 个**（自身） |
| 跨设计选择器混入 | **0**（逐文件标记实测） |

**结论**：隔离契约是干净的，任何预览方案都不得破坏它。

## 2. 令牌声明现状（风险点）

| 设计 | 令牌声明选择器 | 属性数 |
|---|---|---|
| `fast` | `.fs` | 16 |
| `frost` | `.fr` | 17 |
| `govuk` | `.gv` | 18 |
| `kern` | `.kern` | 13 |
| `material3` | `.m3` | 29 |
| `pager` | **`:root`** | 18 |
| `archive` | **`:root`** | 9 |
| `tape` / `radio` / `receipt` / `fax` / `poster` / `lexicon` | 各 body 类 | 6–18 |
| `editorial` / `terminal` | 仅 `@theme inline` 字体映射 | 1 |

- **`:root` 声明是不可接受的预览形态**：组件 `<style>` 里的 `:root` **不被 Astro 作用域化**（实测：原样输出为全局 `:root{...}`），会污染切换页全局。
- 作用域类（`.fs` / `.m3` …）本身是命名空间化的，泄漏风险低，但仍需确认预览根元素带该类。

## 3. 推荐架构：设计私有 `Preview.astro` + 共享令牌文件

### 3.1 文件契约

```
src/designs/<id>/
├─ tokens.css          # 新增（可选）：设计私有令牌，纯 CSS，无 Tailwind
├─ Preview.astro       # 新增（可选）：自包含预览碎片
├─ style.css           # 既有：改为 @import "./tokens.css"（可选改造）
└─ Page.astro          # 既有：不变
```

- `tokens.css` 是令牌的**单一来源**：正式页 `style.css` 与预览 `Preview.astro` 都 import 它。
- `Preview.astro` 的样式放组件自己的 `<style>`（Astro 自动作用域化）。
- **四件套契约不变**：`Preview.astro` / `tokens.css` 均为可选附加文件，缺失不报错（与 `receipt/Ticket.astro` 同类）。

### 3.2 实测证据

探针：`src/designs/pvxprobe/{tokens.css, style.css, Preview.astro, Page.astro}` + 切换页式页面。

| 断言 | 实测结果 |
|---|---|
| 预览页链接的样式表 | **0**（预览 CSS 全部内联） |
| 预览页含 Tailwind preflight | **否** |
| 预览页含整页规则（`.pvx-page`） | **否**（`style.css` 未泄漏） |
| 设计页含预览规则（`.pvx-prev`） | **否**（预览未泄漏回正式页） |
| 共享 `tokens.css` 在两处均生效 | **是**（预览内联令牌 + 设计页链接 CSS 均含 `.pvx-root`） |
| 组件 `<style>` 作用域 | `[data-astro-cid-*]`，16 组件同页**零冲突** |
| 16 组件产出的 CSS 资源数 | **1 个**（非 16 个 `<link>`） |
| 纯 CSS 顶层 import（`tokens.css`） | 内联；令牌类**保持未作用域**（命名空间化类，符合预期） |
| `:root` 写在组件 `<style>` 内 | **未作用域化 → 全局泄漏**（必须禁止） |
| 字体是否去重 | **否**：同 `<Font>` 声明 2 次 → 2 份 `@font-face`；3 组件各声明 → 18 份 |
| eager glob `./*/Preview.astro` | **把预览 CSS 内联进无关页面**（陷阱复现） |
| 组件 import `style.css` | 产出**带 Tailwind preflight 的链接样式表**（反例） |

### 3.3 三条硬约束（由实测推导）

1. **预览不得 import `style.css`**：会带进 4–5KB Tailwind preflight 与整页规则。
2. **令牌不得写在 `:root`**：组件 `<style>` 的 `:root` 不被作用域化。预览令牌必须作用域在**设计命名空间的类**上（如 `.ar-pv`），且不得使用 `:root`。
3. **不得 eager glob 预览组件**：会把预览 CSS 聚合进任何引用该模块的页面。发现机制必须走**显式静态 import**。

### 3.4 字体策略（用户已批准 CJK 下载）

- 字体在**切换页页面级声明一次**，按 `cssVariable` 的 family **去重**（`new Set()` 收集）。
- 预览只声明自己**真正渲染**的字体；不渲染中文的预览不必引入 CJK 子集。
- 实测成本参考（单套设计，浏览器按 `unicode-range` 取用）：

| 设计 | latin 子集 | CJK 子集 |
|---|---|---|
| `fast` / `govuk` / `oxide` | 0（系统字体） | 0 |
| `terminal` | 84KB | 0 |
| `editorial` | 80KB | 0 |
| `material3` | 103KB | 0 |
| `archive` | 199KB | 246KB |
| `fax` | 132KB | 550KB（TT2020 Style D 304KB + Zhuque 246KB） |

**关键洞见**：CJK 成本由**预览渲染什么文字**决定，而非设计本身。拉丁/ASCII 样例文字可省 250–550KB；用户已选择接受 CJK 成本换取忠实度。

## 4. 发现机制（避开聚合陷阱）

- **切换页 `SwitcherPage.astro` 显式静态 import 各预览组件**。切换页**本来就该**拥有全部预览 CSS；泄漏风险只存在于「多页共享模块 glob 预览」。
- 现有先例一致：`descriptions.ts` 是**手工维护的纯数据索引**，不 import 设计模块。
- 规模取舍：114 套时手工维护 114 行 import 冗长但**简单且无泄漏**；生成清单（构建期脚本）属「过早引入的复杂机制」，本轮**不做**，仅记录为规模评估结论。

## 5. 规模成本评估（R7 / A9）

| 方案 | 16 套 | 114 套 | 判定 |
|---|---|---|---|
| 现状（仅色点） | 36KB HTML，0 CSS | 同量级 | 无预览 |
| 各设计 `style.css` 全引入 | 209KB CSS | ~1.5MB | **不可接受** |
| iframe 真实页面 | ~1MB+ | ~7MB | **不可接受** |
| **推荐：自包含 Preview.astro** | ~2.5KB 预览 CSS + 去重字体声明 | ~285KB CSS（按 2.5KB/套估） | 需缓解措施 |

**114 套的瓶颈是 DOM 节点数与 CSS 体积，不是网络请求数**（预览 CSS 聚合为单资源）。

缓解次序（**先简单、后复杂**）：
1. **`content-visibility: auto`** 兜底离屏卡片的渲染成本（零 JS、静态兼容）；
2. 预览**极简**：只呈现视觉签名，不复制整页信息结构（约束预览 CSS 在 1–3KB）；
3. 仍不可接受时，再评估**按来源形态 / 视觉族分页**——本轮不实施。

## 6. 边界与不变量

- **不改**：`Page.astro` 的设计表达、`style.css` 的整页规则、注册表四件套契约、`descriptions.ts` 数据结构、共享操作菜单、动效机制。
- **不引入**：新依赖、Tailwind 到预览层、运行时 JS、`<img>` / 截图资产、服务器依赖。
- **保持**：切换页的中性基础设施定位（不模仿任何一套设计；预览是「内容区的引述」，不是页面换肤）。
- **构建期守卫**（建议）：`registry.ts` 增加校验——若 `<id>/Preview.astro` 存在，则其内容不得出现 `import './style.css'` 之类的整页样式边；违规即构建失败并指明目录与原因（与既有校验风格一致，用 `node:fs` 读文件 + 正则，不建立模块边）。

## 7. 风险与对策

| 风险 | 对策 |
|---|---|
| 共享模块 glob 预览 → CSS 聚合 | 显式静态 import；registry 守卫；A2/A3 产物断言 |
| `:root` 令牌泄漏 | 预览令牌作用域在命名空间类；A4 断言 |
| 字体成倍放大 | 页面级按 family 去重；A5 计数断言 |
| 预览污染其他设计页 | 预览 CSS 只出现在切换页；A3 断言 |
| 预览退化为通用卡片 | R2 视觉验收（A6）：对照正式页目检，要求「一眼可认」 |
| 114 套渲染成本 | `content-visibility` 兜底 + 预览极简；A9 评估结论 |
| 预览与正式页视觉漂移 | 令牌单一来源（`tokens.css`）；预览是引述而非复刻，漂移受限于令牌层 |
| CJK 下载成本 | 用户已批准；记录实测字节数，不渲染中文的预览不引入 CJK |

## 8. 与既有决策的关系

- 本方案**不违反** `SPEC.md §8` 第 7 条：预览令牌是**设计私有**的，不是「跨设计共享 Token」；切换页不合并任何设计的样式。
- 本方案**规避** `AGENTS.md`「已知坑」的 CSS 聚合陷阱：不建立共享模块到设计 CSS 的动态导入边。
- 本方案与 `docs/adr/0007`（共享操作菜单 = 项目级 chrome 的唯一例外）**不冲突**：预览不是 chrome，是设计内容的引述，归属各设计。

## 9. 实施期补充实测（2026-10-18，进入 Phase 2 前）

§3.2 的探针只验证了「单个预览组件」的行为。实施前补做了三个**体量 / 去重**探针（探针已清除），
结论修正了两处规划假设，必须并入实施契约。

| # | 断言 | 实测结果 | 对规划的影响 |
|---|---|---|---|
| F1 | 组件内 `<Font>` 声明 | **不去重**：页面级 2 族 → 15 个 `@font-face`；组件内再声明同一族 → **22 个**，且 `<style>` 块落在**组件所在 DOM 位置**（body 内） | 预览组件**禁止**声明 `<Font>`；字体一律由切换页**页面级去重**声明 |
| F2 | `.astro` frontmatter 具名导出 | **可被调用方读取**（`import Exp, { fonts } from './Exp.astro'` 实测取到值） | 预览可导出自己用到的字体清单，切换页据此收集去重 |
| F3 | 16 个**不同**预览组件聚合 CSS | 超出 Astro `build.inlineStylesheets: 'auto'` 的 4KB `assetsInlineLimit` → 产出一个**独立 `<link>`**（实测 48KB），而非内联 | A2 措辞需精确化：禁止的是**设计 `style.css` 的 `<link>`**；切换页自有的**单个预览样式表**是可接受且更优的（避免把 ~48KB 内联进三语言 HTML） |
| F4 | 16 个**相同**组件 | 去重为 **1 个内联 `<style>`**（按内容去重） | 同一设计三语言共享同一份预览 CSS（同 entrypoint） |

### F3 的补充证据（隔离未被破坏）

- 该预览样式表**不含** Tailwind preflight（无 `--tw-`）、**不含** `:root` 设计令牌、**不含**任何设计整页选择器。
- 设计页（`/zh-cn/terminal/` 等）仍**恰好 1 个** `<link>`（自身），产物中**不出现**预览选择器。
- 三个语言的切换页**不引入**对方内容；预览 CSS 归属 `SwitcherPage.astro` entrypoint。

### F1 的补充证据（字体变量的 `:root`）

- Astro 的 `<Font>` **总是**输出 `:root{--font-<name>: ...}` 字体族变量（设计页同样如此）。
- 这是**框架产出的字体变量**，不是设计令牌；变量名以 `--font-` 前缀命名空间化。
- A4 的判据据此精确化为：禁止的是**设计令牌**（`--ar-*` / `--fast-*` 等）出现在 `:root`；
  框架字体变量属于不可避免且无冲突的一类，须在验证记录中显式说明。

### F5 令牌抽取的真实风险（`archive`）

`archive` 的 `:root` 令牌被**祖先选择器消费**：

```css
html { background: var(--ar-back-deep); scrollbar-color: var(--ar-dim) var(--ar-back-deep); }
```

自定义属性只**向下继承**，`html` 是 `.ar`（body）的祖先——令牌一旦从 `:root` 迁到 `.ar`，
该规则**取不到值**。故 `archive` 的抽取必须同时把这条 `html` 规则的取值改为**字面量**
（与 `--ar-back-deep` / `--ar-dim` 同值，注释说明），并逐像素比对正式页不变。
`tokens.css` 的选择器**只能是类**（`:is(.ar, .ar-pv)`）——任何全局选择器都会随预览内联泄漏到切换页。
