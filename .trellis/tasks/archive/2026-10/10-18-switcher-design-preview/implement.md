## 实施结果（2026-10-18 完成）

**阶段 0–4 全部执行完毕。** 结论如下（完整实测证据见 `docs/verification/shared.md` 的「切换页设计预览」节）：

- **阶段 1**：3 套原型落地 —— `terminal`（琥珀屏 + 扫描线 + `$ whoami`）、`archive`（木抽屉 + 马尼拉卡 + 类目签 + 点引导 + 红章）、`fast`（企业 hero + 品牌蓝按钮 + 三卡网格）。每套新增 `Preview.astro` + `tokens.css`；`style.css` 改为 `@import "./tokens.css"`。
- **阶段 2**：A1 ✅（73 页 / 0 错 0 警 1 条既有提示）、A2 ✅（切换页恰 1 条样式表、0 preflight、0 整页选择器）、A3 ✅（16 套 × 3 语言设计页 0 预览选择器；基础设施页 0 样式表）、A4 ✅（切换页 `:root` 设计令牌 0）、A5 ✅（`@font-face` 21 = 4 族去重，反证加同族不变）、A8 ✅（移出预览仍绿、回退色点卡片、哈希还原一致）。
- **阶段 3**：A6 ✅（三套对照正式页「一眼可认」）、A7 ✅（CDP 无障碍树：预览文字零泄漏、0 可聚焦、Tab 不进预览）、检测器 0 条（反证探针确认检测器确实会命中）。
- **阶段 4**：A9 ✅ 见下表；**A10 待用户验收**。

**实施期新增发现（不在原计划内）**

1. **真实缺陷**：`style.css` 的 `@source "./"` 会连带扫描同目录 `Preview.astro`，把其 `<style>` 属性文本当工具类注进**正式页** CSS（约 +1.3KB/页，且「改预览」静默影响正式页样式）。已加 `@source not "./Preview.astro";` 修复。**这是本任务唯一超出「只新增预览层」的改动，且它修复的是新增预览引入的副作用。**
2. **检测器提示的归属**：预览的缩略档位（更小的字号 / 圆角）登记进该设计 `DESIGN.md` 的阶梯（`archive` 三档、`terminal` 三档 + `rounded.preview-frame`），而非加忽略规则——检测器读的就是 `DESIGN.md`，登记后立即归零。`fast` 为厂商来源、快照无阶梯、本就 0 条。
3. `archive` 的 `html` 规则是 `.ar` 的**祖先**，令牌迁走后取不到值 → 改字面量（同值）。这是 F5 风险的落地实例。

**A9 规模结论**

| 口径 | 基线（0 预览） | 3 套 | 16 套 | 114 套 |
|---|---|---|---|---|
| 切换页 CSS | 0 | 10.1KB（单资源） | ≈54KB | ≈386KB |
| 切换页 HTML | 35.6KB | 46.8KB | ≈57KB | ≈188KB |

- 瓶颈是 **CSS 体积 + DOM 节点数**，不是请求数（预览 CSS 聚合为单个样式表，三语言共享）。
- **建议**：铺开方式由用户裁定；若铺开，先落 `content-visibility: auto`（零 JS、静态兼容）兜底离屏卡片，并保持每套预览 1–3KB。**分页 / 按需加载属过早优化，本轮不引入**（R7）。
