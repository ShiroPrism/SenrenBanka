# 切换页设计预览：自包含 Preview.astro 方案

> 为 `/{locale}/designs` 切换页的每个设计选项提供**不依赖静态截图**的视觉预览。
> 技术设计与本轮实测证据见本目录 `design.md`；执行协议与检查清单见 `implement.md`。

## Goal

切换页当前只用「displayName + 本地化描述 + accent 色点」表示一套设计，访客在点进去之前无法感知该设计的视觉语言。本任务为每个设计选项增加**轻量视觉预览**，使其在不离开切换页的前提下体现该设计最有辨识度的**布局骨架、字体角色、配色与签名装饰**。

用户价值：切换页从"文字清单"升级为"可目视比较的设计选择界面"；且该预览**不依赖静态截图**——截图会随设计演进过期、需要额外维护管线、无法随语言变化，并引入二进制资产与许可问题。

## 背景与已确认事实（2026-10-18 调研实测）

- 切换页 `src/infra/SwitcherPage.astro` 刻意保持**零设计依赖**：实测产物 36KB HTML、**0 个样式表链接、0 个 `@font-face`**，样式全部来自 `InfraStyles.astro` 内联；描述文案经纯数据模块 `src/designs/descriptions.ts` 汇总（**不 import 任何设计模块**）。
- CSS 隔离现状良好：16 套设计各自编译出 9–16KB CSS（其中 4–5KB 为 Tailwind preflight/theme 基线），**每套设计页只链接自己那一个文件**，互不混入（逐文件标记实测）。
- 设计令牌声明位置**不统一**：多数设计作用域在自己的 body 类（`.fs` / `.m3` / `.tp` 等），但 `archive` 与 `pager` 把令牌写在 **`:root`**——后者在预览语境下是全局泄漏通道。
- 字体是主要成本变量：23 个字体族（`src/assets/fonts/` 17 族 1186KB）；`fast` / `govuk` / `oxide` 用系统字体（0 字节）；CJK 子集为大头（Zhuque Fangsong 246KB、TT2020 Style D 304KB、Ark Pixel 39KB）。浏览器只按 `unicode-range` 下载实际用到的子集。
- **用户决策（2026-10-18）**：预览文字**允许触发 CJK 子集下载**（即预览可渲染中文/日文，接受 zh-cn 切换页 +250~550KB 的字体成本）。
- 相关既有规则：`AGENTS.md`「已知坑」的 CSS 聚合陷阱（多页共享模块对设计 CSS 建立动态导入边会把所有设计 CSS 聚合进每个引用页）；`SPEC.md §3.2` 第 2/4/11 条；`SPEC.md §8` 第 7 条「禁止把所有设计样式合并进公共 CSS、禁止跨设计共享设计 Token」。

## Requirements

- **R1 可选 Preview.astro**：每套设计**可选**提供 `src/designs/<id>/Preview.astro`——自包含的"首屏碎片"，只呈现该设计的视觉签名，**不是**完整页面、不带动效机制、不引入交互依赖。注册表四件套契约**不得**因此变更（预览缺失必须可构建）。
- **R2 视觉辨识度**：预览必须体现该设计最有辨识度的布局骨架、字体角色、配色与签名装饰，**不得**退化为统一的通用卡片模板；`terminal` 等特殊设计必须保留自身视觉特征（屏框、扫描线、命令提示行等）。
- **R3 令牌复用、整页隔离**：预览与正式页**共享设计令牌**（设计私有令牌文件，单一来源），但**不得**直接引入 `style.css`、完整 `Page.astro` 或其脚本 / 交互依赖。
- **R4 隔离硬约束**：预览样式**不得**污染切换页或其他设计；切换页**不得**新增 Tailwind preflight；**不得**产生 `:root` 令牌泄漏；**不得**用 eager glob 让设计 CSS 聚合进无关页面。
- **R5 字体开销受控**：切换页的字体声明按 family **去重**（页面级一次），不得随预览数量成倍增长；预览只声明自己真正渲染用到的字体。
- **R6 优雅回退**：无 `Preview.astro` 的设计**回退**到现有 accent 色点卡片，不强制迁移、不出现破版。
- **R7 规模可扩展**：设计数将从 16 扩至 114（`SPEC.md §4.4`）。本轮先做 **3 套原型**验证，再决定是否铺开；**不得过早引入**分页 / 按需加载等复杂机制。
- **R8 静态部署兼容**：保持纯静态构建产物，**不引入**任何必须依赖服务器运行的方案。

## Acceptance Criteria

- [ ] A1 `npm run build` 绿（页面数不变：预览不得新增路由），`astro check` 0 错误 / 0 警告 / 0 提示。
- [ ] A2 **零设计 CSS 泄漏**：切换页产物中**不出现**任何指向 `style.css` 编译产物的 `<link>`；切换页不新增 Tailwind preflight。
- [ ] A3 **零跨设计污染**：任一设计页产物中不出现预览组件选择器；切换页不出现任一设计的整页规则（如 `.fs-cards` / `.m3-` 等页面级选择器）。
- [ ] A4 **无 `:root` 泄漏**：切换页内联样式中不存在由预览引入的全局 `:root` 令牌块。
- [ ] A5 **字体计数受控**：切换页 `@font-face` 数量等于「预览实际用到的 family 去重数」，与预览组件数量**不成正比**；记录实测数值。
- [ ] A6 **视觉验收**：3 套原型桌面 / 移动 / 三语言截图目检通过；预览能一眼认出该设计的视觉语言（对照其正式页）。
- [ ] A7 **无障碍**：预览为装饰性呈现，不进入可访问名与焦点顺序；卡片链接的可访问名与语义不因预览而退化；对比度不劣化。
- [ ] A8 **回退可用**：人为移除某原型 `Preview.astro` 后构建仍绿，该卡片回到色点形态且不破版。
- [ ] A9 **规模评估**：给出 16 套与 114 套两种情形下的切换页 CSS / 字体 / DOM 成本估算与瓶颈结论，明确是否铺开及铺开方式。
- [ ] A10 用户验收通过（否决则回炉）。

## Out of Scope

- 修改任一设计的正式页视觉（`Page.astro` / `style.css` 的设计表达）——本任务只新增预览层。
- 静态截图 / 缩略图管线（明确排除：会过期、需额外维护、引入二进制资产与许可问题）。
- iframe 内嵌真实设计页（实测成本不可接受：16 套 ≈1MB+，114 套 ≈7MB）。
- 切换页分页 / 搜索 / 筛选 / 按需加载等复杂机制（R7：先原型，后评估）。
- 新增生产依赖；改动字体生产管线与 `.local-fonts` 工具契约。
