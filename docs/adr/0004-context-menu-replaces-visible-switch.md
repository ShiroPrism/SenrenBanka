# 设计切换入口改为共享桌面右键快捷操作菜单：移动端无入口、原生右键保留、统一中性外观

> **部分被 [ADR 0007](./0007-action-menu-site-wide-with-touch-launcher.md) 取代**：决定 2 的"触屏设备不提供菜单 / 不加载菜单逻辑 / 无任何移动端替代入口"与被否决项第 2 条"移动端替代入口"已被推翻——v0.10.0 起改为悬浮球入口 + 底部动作面板。本文件保持原文不动（决策只追加不修改），当前有效版本以 0007 为准。决定 1、3、4、5、6 与其余被否决项仍然有效。

## 背景与决定

v0.5.0 前，每套设计必须自留一个可见的 `Switch design` 入口（Q4 初版契约：形式自由、无 JS 可达）。项目所有者决定改为**统一的桌面端自定义右键菜单**（页面操作 + 设计操作），并移除全部可见旧入口。菜单由项目所有者提供示意图（中性灰白、页眉显示「SENRENBANKA · 当前设计」），三项待决经确认后落定：

1. **外观 = 统一中性 chrome（不做逐设计主题化）**：四套设计共用一套与 `/designs/` 切换页同属基础设施 UI 的样式，随系统明暗（`light-dark()`）；不建立逐设计 token 覆盖。理由是示意图本身即中性外观、隔离成本最低，且项目已有"切换页中性极简、不模仿任何设计"的先例。
2. **触发只限桌面鼠标环境**：`(hover: hover) and (pointer: fine)` 门控 + 动态 `import()` 按需加载运行时；**触屏设备不提供菜单、不模拟长按、不加载菜单逻辑**，设计页也不保留任何移动端替代入口（项目明确取舍：移动端放弃页内切换，固定 URL 与 `/designs/` 直达仍可用）。
3. **原生右键保留**：链接、图片、输入控件、可编辑区、已选中文字、触屏来源（混合设备长按）一律交还浏览器原生菜单；**不得对全页无条件 `preventDefault()`**。自定义菜单只在"确认接管"时才阻止默认行为。
4. **随机语义完全复用既有存储契约**：`storageKey` / `{ designId, expiresAt }` / `withBase()`；额外要求**必须排除当前设计**（否则"随机"可能停在原地），`avoidRepeat` 时再尽量排除上次；仅一套启用设计时该项 `aria-disabled`；写入后直接 `location.assign` 目标固定 URL，不回根路径。页面加载与打开菜单都不写存储。
5. **实现唯一来源 = 共享组件**：`src/components/ContextMenu.astro` + `src/lib/context-menu.ts`；样式 `<style is:inline>`（不新增 `<link>`，不破坏"每设计页只链接自己的 CSS"）；禁止逐设计复制菜单实现。
6. **反馈**：复制（Clipboard API → `execCommand` 降级 → 失败提示）与分享（成功 / 取消 / 失败）以 Toast（`role="status"`）呈现；`navigator.share` 不可用时**移除**「分享页面」项。

## 被否决的选项

- **移动端替代入口**（汉堡按钮 / 长按菜单）：项目所有者明确"移动端不提供页面内切换"，同时避免为触屏维护第二套交互与额外运行时。
- **逐设计主题化菜单**：与"中性 chrome"先例冲突，且需在四份 `style.css` 各加 token 块、放大隔离与验证面。
- **静态 import 运行时 + 内部早退**：触屏设备仍会下载菜单逻辑，违背"不为触屏额外加载"。
- **全页 `preventDefault()`**：破坏链接 / 图片 / 输入 / 选中文字的原生上下文操作。
- **随机后回根路径 `/`**：会被随机缓存（`cacheHours`）把用户送回当前设计，违反"确实发生切换"。
- **保留页脚可见入口作兜底**：与"删除全部可见 Switch design 入口"相抵触；桌面无 JS 用户改由 `/designs/` 直达承担。

## 后果

- 桌面端无 JS 用户没有页内切换入口（可直达 `/designs/`）；这是接受的取舍。
- 新增设计时"切换入口"= 接入共享组件（docs/rules/action-menu.md 已更新），不再自建链接；`manualSwitch:false` 时组件整体不渲染且 `/designs/` 404。
- oxide / fast 的 `DESIGN.md` 为厂商快照未修改；terminal 自产规范的"禁止 SVG 图标"约束在 Project Contract 中注明不适用于项目级 chrome 的菜单图标（lucide）。
- 菜单样式与运行时属项目 chrome，其改动（尺寸 / 图标 / 项）应保持中性语言，并重跑 `design-page-verify`。
